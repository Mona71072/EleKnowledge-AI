# 会議資料

会議の説明・検討用に準備した資料を、開催日ごとのフォルダーに保管します。現行の配布資料とは分け、後からその会議に向けた説明内容・検討事項を確認するための記録として扱います。

| 開催日 | 会議・資料 |
| --- | --- |
| 2026年10月15日 | [Ele-Knowledge キーマン打合せ](2026-10-15/README.md) |

## 保管場所の使い分け

- `YYYY-MM-DD/`：会議向けに準備した資料。資料中の作成日や当時の計画を残し、後日の仕様変更には追従させません。
- [利用者向け資料](../user-manual/README.md)：利用者へ配布する現行のマニュアル・FAQ。
- [キーマン向け資料](../key-persons/README.md)：キーマンへの共有資料とForms原稿。今回の議事録もここを正本とし、会議フォルダーからリンクします。

同じ資料の本文を複数の場所で保管・更新せず、会議のREADMEから参照先へ案内します。準備資料に含まれる構想や予定は、現在の実装・提供状態や会議での決定事項を示すものではありません。
