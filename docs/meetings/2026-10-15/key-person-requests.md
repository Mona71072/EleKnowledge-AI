# キーマンへのご相談・依頼事項

> 打ち合わせ用ドラフト（2026-10-02時点）。概要PDFと今回の確認に基づき、昇モ工は2026年11月から資料拡充準備、12月リリース予定。具体日・範囲・受入条件は未確定。

## ご相談の目的

昇モ工で役立つ資料と質問を一緒に選び、原資料に基づいて検索結果を確認する進め方をつくりたいと考えています。キーマンには、業務上の優先順位と資料・回答の妥当性を確認いただき、開発側だけでは判断できない点をご助言いただきたいです。

## ご協力いただきたいこと

| 項目 | お願いしたいこと | 確認・成果物 |
|---|---|---|
| 1. 優先業務・資料の選定 | まず解決したい業務上の質問や、参照頻度・重要度の高い資料を挙げていただく | 優先テーマと資料候補 |
| 2. 資料の確認 | 資料の所管、最新版、対象者、登録・利用可否、機密・個人情報の有無を所管者と確認する | 登録可否、版・保管元、確認担当 |
| 3. 実務質問の提供 | 実際によくある質問を数件共有いただく。特定できる個人情報や機密情報は含めない | 評価用の質問例 |
| 4. 検索・回答の確認 | 質問に対して、必要な資料が候補に出るか、根拠と回答が妥当かを原資料と照合する | 良い例・不足例・修正優先度 |
| 5. 評価結果・改善要望の取りまとめ | 部門内の確認結果、回答精度の課題、改善要望を集約する | 優先順位付きの改善要望 |
| 6. 資料更新の相談 | 資料の改訂・廃止を誰が把握し、誰が登録・確認するかを相談する | 継続運用の担当案 |

資料の登録や利用は、所管・権限を確認してから進めます。所管や利用可否が確認できない資料は、確認が取れるまで登録対象にしません。

## 打ち合わせ頻度・活動方法の提案

**提案:** 概要PDFにある「月1〜2回程度」を基本案とし、資料精査、AI回答精度の確認、評価結果・改善要望の取りまとめを行う。会議の間は資料一覧や回答例を共有し、必要な箇所だけ随時確認いただく。

| 期間 | 活動案 | 頻度案 |
|---|---|---|
| 初回 | 昇モ工のキーマン候補、優先業務・資料、所管・利用可否を確認 | 初回打ち合わせ |
| 資料精査 | 資料候補・版・所管・登録可否を確認し、対象を絞る | 月1〜2回程度の定例＋会議間の資料確認 |
| 回答精度確認 | 実務質問で検索結果・根拠・回答を確認し、改善点をまとめる | 月1〜2回程度。準備期間に合わせて必要回数を相談 |
| リリース後 | 利用者の声、未到達資料、改善要望をまとめる | 月1〜2回を継続するか、初回レビュー後に再相談 |

概要PDFでは工事統括部の各部門から2名ずつ、計12名を選定する案が示されています。昇モ工についても2名を候補とするか、役割分担（資料精査／回答確認・要望集約）とあわせて相談します。参加者・所要時間・会議間の確認方法はキーマンのご都合に合わせて決めます。

## リリース前に一緒に確認したい条件（案）

- 優先対象の資料について、所管・最新版・利用可否が確認できている
- 実務上重要な質問例で、関連資料が検索候補に現れることを確認できている
- 回答と根拠の不一致、誤解を招く表現、根拠不足時の扱いを確認している
- AIの回答を最終判断とせず、原資料確認が必要な場面が利用者に伝わる
- リリース後の資料更新・問い合わせ・改善要望の窓口が決まっている

これは合意前のたたき台です。質問数や達成基準、リリース判断者は打ち合わせで相談し、実務に合う形に調整します。
