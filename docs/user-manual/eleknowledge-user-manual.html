1. はじめに

1.1 EleKnowledge でできること

EleKnowledge（画面表記: EleKnowledge、サポート名: Ele-Knowledge）は、昇降機の技術資料（据付基準、C資料、TI、現場代理人業務マニュアルなど）を検索し、参考資料（根拠）つきで質問に回答する社内向けのチャット型検索システムです。

  • 困りごとをそのまま日本語で質問できます。
  • 回答には「該当頁候補」と「参考資料」が付き、元の PDF をその場で開いて確認できます。
  • 資料の種類や機種で検索対象を絞り込めます。
  • 回答が役に立ったかどうかを「解けた／解けない」で送ると、改善に活かされます。
  • 過去のチャットは履歴として残り、後から開き直せます（60日で自動削除）。
回答の扱いについて

回答は AI が資料をもとに要約したものです。現場判断は必ず「参考資料」の原本（PDF）で確認してください。回答の先頭に「※機種未指定のため…」と表示された場合は、特定機種の事実として断定しないでください。

2. アカウントを作る（サインアップ）

2.1 できること・前提

初めて使うときに一度だけ行います。会社のメールアドレスとパスワードを登録し、メールで届く確認コードを入力すると利用を開始できます。

操作前に必要なもの
  • 会社のメールアドレス（@meltec.co.jp または @○○.mitsubishielectric.co.jp）と、そのメールを受信できる Outlook 等。
  • パスワード: 8文字以上で、大文字・小文字・数字・記号（! @ # $ % など）をすべて含むもの。

2.2 手順（アカウント作成画面）

  1. 必須ブラウザで接続先 URL を開きます。ログイン画面が表示されます。
  2. 必須ログイン画面の下にある アカウントを作成 を押します。「アカウント作成」画面が開きます。
  3. 必須1 名前 に氏名を入力します（2文字以上。例: 現場 太郎）。ホーム画面の「こんにちは、○○さん」に表示されます。
  4. 必須2 メールアドレス に会社のメールアドレスを入力します。
  5. 必須3 パスワード を入力します。入力すると 4 の強度表示が更新され、満たした条件が緑の点になります。5つすべてが緑になるまで入力してください。
  6. 任意目のマークを押すと、入力したパスワードを表示して確認できます。
  7. 必須5 登録 を押します。「メールアドレスの確認」画面に切り替わります（2.3へ）。

2.3 手順（メールアドレスの確認画面）

  1. 必須Outlook で、差出人 no-reply@verificationemail.com、件名 Your verification code のメールを開きます。本文の Your confirmation code is の後ろにある6桁の数字が確認コードです。
    メールが見つからないとき
    受信トレイ直下ではなく「社外メール」や「迷惑メール」のフォルダーに振り分けられていることがあります。数分待っても届かない場合は、画面の 確認コードを再送信 を押してください（押した後60秒間は再度押せません）。
  2. 必須2 確認コード（6桁） の枠に、左から順に数字を入力します。1桁入れると自動で次の枠に移ります。メール本文の6桁をコピーして貼り付けても入力できます。1 のメールアドレスは自動で入り、変更できません。
  3. 必須6桁入力すると 3 確認 が押せるようになるので押します。
  4. 青いメッセージ「メールアドレスが確認されました。…」が表示されます。
    • 「ホーム画面に移動します...」と出た場合: 自動でログインされ、約1.5秒後にホーム画面が開きます。これで完了です。
    • 「ログインページに移動します...」と出た場合: 約2秒後にログイン画面が開くので、登録したメールアドレスとパスワードでログインしてください（3章）。

2.4 想定どおりにならない場合

表示・状況対処
「このメールアドレスは既に登録されています。」すでにアカウントがあります。ログイン画面からログインしてください。パスワードが分からない場合は 3.4「パスワードを忘れたとき」へ。
「登録に失敗しました。もう一度お試しください。」会社のメールアドレス以外（@meltec.co.jp／@〜.mitsubishielectric.co.jp 以外）は登録できません。アドレスを確認して再度登録してください。それでも失敗する場合はサポートへ連絡してください。
「確認コードが正しくありません。」最新のメールのコードを入力し直してください。再送信した場合は、最後に届いたメールのコードが有効です。
「確認コードの有効期限が切れています。…」確認コードを再送信 を押し、新しいコードを入力してください。
確認画面を閉じてしまったログイン画面でメールアドレスとパスワードを入力してログインすると、確認画面に自動で移動します。

3. ログインする／ログアウトする／パスワードを忘れたとき

3.1 ログインする

前提: 2章でアカウント作成とメールアドレスの確認が済んでいること。

  1. 必須ブラウザで接続先 URL を開きます。ログイン画面が表示されます（ログイン中に開いた場合も、この画面を開いた時点でログアウト状態になります）。
  2. 必須1 メールアドレス を入力します。
  3. 必須2 パスワード を入力します。任意3 目のマークで入力内容を表示できます。
  4. 必須4 ログイン を押します（Enter キーでも送信できます）。
  5. ホーム画面（4章）が表示されれば完了です。
ログイン状態の有効期間

ログインから24時間はブラウザを閉じても再ログインなしで利用できます。24時間を過ぎると自動的にログイン画面に戻るので、再度ログインしてください。

3.2 想定どおりにならない場合（ログイン）

表示・状況対処
「メールアドレスまたはパスワードが正しくありません。」入力内容を確認して再入力してください。何度も失敗すると一時的にログインできなくなるので、数分〜15分ほど待ってから再度お試しください。パスワードが分からない場合は 3.4 へ。
「メールアドレスの確認が必要です。…」と出て確認画面に移動したアカウント作成時の確認コード入力が済んでいません。2.3 の手順で確認コードを入力してください。
「ログイン試行が多すぎます。後でもう一度お試しください。」しばらく時間をおいてから再度お試しください。
「ネットワーク接続エラーです。…」／画面自体が表示されない社内ネットワークに接続しているか確認してください。社外からは利用できません。

3.3 ログアウトする

  1. 必須ホーム画面の右上にある ログアウト を押します（RAGチャット画面では、先に ホームへ戻る を押します）。
  2. ログイン画面に戻れば完了です。共用PCでは、離席時に必ずログアウトしてください。

3.4 パスワードを忘れたとき（パスワードリセット）

前提: 登録したメールアドレスでメールを受信できること。

  1. 必須ログイン画面の パスワードを忘れた を押します。「パスワードリセット」画面（ステップ1: メール送信）が開きます。
  2. 必須1 メールアドレスを入力し、2 リセットコード送信 を押します。「パスワードリセットコードがメールアドレスに送信されました」と表示され、ステップ2の入力欄に切り替わります。
  3. 必須メールで届いたリセットコード（数字）を 1 メールで受け取ったコード に入力します。
  4. 必須2 に新しいパスワード（8文字以上、大文字・小文字・数字・記号を含む）を入力し、3 に同じパスワードをもう一度入力します。
  5. 必須4 パスワードリセット を押します。「パスワードが正常にリセットされました。…」と表示され、約2秒後にログイン画面に戻ります。新しいパスワードでログインしてください。
  6. 任意メールアドレスを間違えた場合は 5 メールアドレスを変更する でステップ1に戻れます。
表示・状況対処
「このメールアドレスで登録されたアカウントが見つかりません。」アドレスを確認してください。未登録の場合は 2章 の手順でアカウントを作成します。
「メールアドレスが確認されていないため、パスワードをリセットできません。」アカウント作成時の確認コード入力が済んでいません。サポートへ連絡してください。
「リセットコードが正しくありません。」／「…有効期限が切れています。」最新のメールのコードを入力してください。期限切れの場合は メールアドレスを変更する でステップ1に戻り、もう一度コードを送信します。
「試行回数が多すぎます。…」しばらく時間をおいてから再度お試しください。

5. 質問を送る

5.1 RAGチャット画面を開く

前提: ログイン済みでホーム画面が表示されていること。

  1. 必須ホーム画面で「RAGチャット」カードの 今すぐ開く を押します（または 質問する／質問例を押します）。
  2. RAGチャット画面が開きます。初めてのときは左の履歴欄に「セッションはまだありません」と表示されます。
番号名称説明
1新規チャット新しいチャット（セッション）を始めます。表示中の会話は履歴に残ります。
2履歴欄過去のチャットの一覧です（9章）。
3質問例押すと入力欄にその文が入ります。そのまま送信するか、書き換えてから送信します。
4絞り込み資料の種類・機種で検索対象を絞り込みます（6章）。
5質問の入力欄質問を入力します。Enter で送信、Shift+Enter で改行です。
6送信質問を送ります。入力欄が空のときは押せません。
7こうなってほしい使い方や表示についての要望を運用チームに送ります（8.3）。
8ホームへ戻るホーム画面に戻ります。

5.2 質問を入力して送る

  1. 必須1 入力欄に質問を入力します。困りごとを文章のまま書いて構いません（例: 現場代理人が着工時に用意する書類は？）。改行したいときは Shift+Enter を押します。
  2. 任意機種や資料の種類が分かっているときは、先に 絞り込み で指定しておくと精度が上がります（6章）。
  3. 必須2 送信 を押すか、Enter キーを押します。
  4. 右側に自分の質問が青い吹き出しで表示され、左側に「考え中...」が出ます。送信ボタンは「送信中」になり、回答が出るまで次の質問は送れません。
  5. 回答が表示されれば完了です。本文は少しずつ表示され、表示が終わると「参考資料」と評価ボタンが出ます（7章）。1回目の送信後、左の履歴欄に今回のチャットが追加されます。
精度を上げる質問のコツ
  • 機種・部位・状況を書く（例: 「AXIEZ の乗場ドアで、開閉時に異音がする」）。
  • 同じチャット内で続けて質問すると、直前のやり取りを踏まえて回答します。別の話題に移るときは 新規チャット を押します。
  • 資料の種類が分かっているときは「絞り込み」を使います（6章）。

5.3 追加の情報を求められたとき（聞き返し）

「異音がする」「動かない」のような症状だけの質問で、機種・部位・状況が書かれていない場合、回答の代わりに「追加で教えてください」が表示されることがあります。

  1. 1 「追加で教えてください」の下に、不足している項目が並びます。
  2. 必須分かる範囲で情報を入力欄に書いて送信します（例: 「AXIEZ、乗場ドア、開閉時」）。任意2 項目のボタンを押すと、その項目の文が入力欄に入るので、続けて内容を書き足せます。
  3. 追記して送ると、直前の質問と合わせて検索され、回答が表示されます。

5.4 「条件に合う頁が十分に見つかりませんでした」と出たとき

検索の結果が弱いときは、見当違いの回答をしないよう、断定した回答をせずに「参考候補（低信頼）」と注意文が表示されます。

  • 機種・症状・対象部位を具体的に書き直して、もう一度質問してください。
  • 資料の種類で絞り込んでいる場合は、3 資料カテゴリの絞り込みを外す を押すと絞り込みが解除され、絞り込みパネルが開きます。そのまま再度質問を送ってください。
  • 「参考候補（低信頼）」の資料名を押すと、その PDF を開いて自分で確認できます（7.3）。

5.5 想定どおりにならない場合（質問の送信）

表示・状況対処
入力欄の下に赤い帯で「エラーが発生しました: …」右端の × で閉じ、少し待ってからもう一度送信してください。送った質問は画面に残っています。繰り返し発生する場合は、表示されたメッセージを添えてサポートへ連絡してください。
「セッション取得に失敗しました: …」履歴の読み込みに失敗しています。ページを再読み込み（F5）してください。改善しない場合はサポートへ。
送信ボタンが押せない入力欄が空か、前の質問の回答待ち（「送信中」）です。回答が表示されるまで待ってください。
ログイン画面に戻ってしまうログインの有効期間（24時間）が切れています。再度ログインしてください。
「考え中...」のまま長時間変わらない1分程度待っても変わらない場合は、ページを再読み込みし、履歴からそのチャットを開いて回答の有無を確認してください。回答がなければ再度質問を送ってください。

6. 資料や機種を絞り込む

6.1 できること

  • 資料（資料の種類）: 複数選択できます。未選択のときはすべての資料が対象です。
  • 機種: 1つだけ選択できます。未選択のときは機種を限定せずに検索します（ただし、取扱外の機種の資料はもともと検索対象外です）。
  • 絞り込みはこれから送る質問に適用されます。同じチャット内で質問ごとに変えられます。
機種を選ばずに質問した場合

回答の先頭に「※機種未指定のため、一般資料・取扱機種スコープ内の候補を含みます。特定機種の事実としては断定しないでください。」と表示されます。特定機種について確認したいときは、機種を選んで質問してください。

6.2 手順

  1. 必須入力欄の上にある 1 絞り込み を押します。絞り込みパネルが開きます。
  2. 任意2 「資料」の行で、対象にしたい資料の種類を押します。押すたびに選択／解除が切り替わり、選択中は青色になります。複数選べます。
  3. 任意3 「機種」の行で、対象の機種を1つ押します。選ぶと「選択中: ○○（名前の完全一致。対象: …。共通資料も含む）」の説明が表示されます。別の機種を押すと切り替わり、同じ機種をもう一度押すと解除されます。
  4. 任意もう一度 絞り込み を押すとパネルが閉じます。選択した内容はボタンの横に青い札で残ります。
  5. 必須質問を入力して送信します。以降の質問にはこの絞り込みが適用されます。

6.3 絞り込みを解除する

  • パネルを閉じた状態: ボタン横の札（例: 据付基準 ×）を押すと、その項目だけ解除されます。× すべてクリア を押すと全部解除されます。
  • パネルを開いた状態: 選択中の項目をもう一度押すと解除されます。機種は すべての機種に戻す でも解除できます。
状況対処
目的の機種が一覧にないこの画面で選べる機種は、担当部門の取扱機種6項目のみです。一覧にない機種の資料は検索対象外です。必要な場合はサポートへ相談してください。
絞り込むと「条件に合う頁が十分に見つかりませんでした」になる資料の種類の絞り込みを外して再度質問してください（5.4）。
新規チャットを押したら絞り込みが残っている絞り込みはチャットを切り替えても残ります。不要なら「すべてクリア」で解除してください。

7. 回答と参考資料を確認する

7.1 回答の見方

番号名称説明
1該当頁候補回答のもとになった資料のページの候補です（最大5件）。資料名・種類・ページ番号・関連度（%）・本文の抜粋が並びます。資料名を押すと、そのページを開いた状態で PDF が別タブに表示されます（7.3）。
2注意書き機種を指定せずに質問したときに表示されます（6.1）。
—回答本文資料の内容を「資料から分かること」「注意・不明点」などに整理した要約です。
3参考資料回答が参照した資料の一覧です。関連度の高い順に上位3件が表示されます。資料名を押すと PDF が別タブで開きます。
4さらに N 件表示4件目以降の参考資料を表示します。折りたたむ で元に戻ります。
5操作ボタン左から、回答のコピー、解けた、解けない（8章）。右端は回答時刻です。
関連度（%）の見方

%は質問と資料の内容がどれくらい近いかの目安です。数値が高いほど関連が強い可能性がありますが、正しさを保証するものではありません。必ず原本で確認してください。

7.2 参考資料の一覧を広げる

  1. 任意3 さらに N 件表示 を押します。残りの資料が表示されます。
  2. 任意折りたたむ を押すと上位3件だけの表示に戻ります。

7.3 資料（PDF）を開いて原本を確認する

前提: ログイン中であること（資料はログインした利用者しか開けません）。

  1. 必須「該当頁候補」または「参考資料」の資料名（青い文字）を押します。
  2. 新しいタブが開き、「文書を開いています…」と表示された後、PDF がブラウザで表示されます。「該当頁候補」から開いた場合は該当ページが表示されます（PDF の表示設定によっては先頭ページになることがあります。その場合は「該当頁候補」に書かれたページ番号 p.○ を参照してください）。
  3. 任意確認が終わったら、そのタブを閉じてチャットのタブに戻ります。
資料の URL について
  • PDF を表示したタブの URL は発行から約5分で無効になります。無効になった後に再読み込みすると「AccessDenied」などの英語のエラーが表示されます。チャット画面に戻り、資料名をもう一度押して開き直してください。
  • PDF の URL を他の人に送っても、相手は開けません（開けても5分以内に限られます）。資料を共有したいときは、資料名（例: GM-01-05-D.pdf）を伝えてください。
  • 資料には「社外秘」などの区分があります。取り扱いは各資料の表示に従ってください。
表示・状況対処
「ログイン画面に移動します…」と出てログイン画面が開いたログインの有効期間が切れています。ログインすると、開こうとした資料に自動で戻ります。
「文書を開けませんでした」チャットに戻る を押して戻り、もう一度資料名を押してください。繰り返し発生する場合は資料名を添えてサポートへ連絡してください。
新しいタブが開かないブラウザのポップアップブロックを確認してください。アドレスバー右端の表示から許可できます。

7.4 回答をコピーする

  1. 任意回答の下にある 1 コピーのマーク（四角が重なった形）を押します。アイコンが緑のチェックに変わり、回答本文がクリップボードにコピーされます。
  2. メールやメモに貼り付けて使えます。参考資料の一覧はコピーに含まれないので、必要なら資料名を別途控えてください。

8. 回答への評価・要望を送る

評価は任意ですが、送っていただくと検索精度や資料の整備に活かされます。評価はチャットごとに記録され、後から変更できます。

8.1 疑問が解けたとき（解けた）

  1. 任意回答の下の 1 解けた を押します。
  2. ボタンが緑色になり、横に 2 「記録しました」と表示されます。画面上部に「ありがとうございます。評価を記録しました。」と一時的に表示されます。これで完了です。

8.2 疑問が解けなかったとき（解けない）

  1. 任意回答の下の 1 解けない を押します。この時点で評価は記録済みです。続けて「詳しく教えてください（任意）」のパネルが開きます。
  2. 任意2 当てはまる理由を1つ押します: 資料が違う（別の資料・機種が出た）／疑問が解けない（読んでも判断できない）／回答がおかしい（要約や断定が違う）／その他。押すと「理由を記録しました。」と表示されます。
  3. 任意3 補足（200字まで）に具体的な内容を書き、4 補足を送る を押します（Ctrl+Enter でも送れます）。「補足を記録しました。」と表示されます。
  4. 任意5 閉じる でパネルを閉じます。理由や補足を書かずに閉じても、「解けない」の評価は残ります。
評価を変えたいとき

もう一方のボタン（解けた／解けない）を押すと評価が置き換わります。「解けた」に変えると、理由・補足は消えます。

表示・状況対処
「評価の送信に失敗しました。もう一度お試しください。」少し待ってからもう一度ボタンを押してください。改善しない場合はサポートへ。
ボタンを押しても反応しない回答本文の表示が終わるまで待ってください。直前の評価を送信中の間も押せません。

8.3 使い方・表示についての要望を送る（こうなってほしい）

回答の評価とは別に、「候補資料をもっと上に出してほしい」のような要望を運用チームに送れます。

  1. 任意RAGチャット画面右上の こうなってほしい を押します。入力用の小窓が開きます。
  2. 必須1 要望を入力します（1000字まで）。
  3. 必須2 送信 を押します。「送信しました。ありがとうございます」と表示され、小窓は自動で閉じます。
  4. 任意送らずにやめるときは 3 閉じる、右上の ×、または Esc キーで閉じます。

9. 履歴（過去のチャット）を開く

9.1 履歴欄の見方

RAGチャット画面の左側に、自分の過去のチャットが新しい順に並びます。他の利用者の履歴は表示されません。

  • 見出し: そのチャットの最初の質問をもとに自動で付きます。
  • N件: そのチャットに含まれる質問と回答の合計数です。
  • 残り N 日: 履歴は最後のやり取りから60日で自動的に削除されます。残り日数が少ない履歴は、必要なら回答をコピーして保存してください（7.4）。

9.2 過去のチャットを開く

  1. 必須履歴欄の 2 開きたい項目を押します。
  2. 右側にそのチャットの質問と回答が表示されます。選択中の項目は青い背景で示されます。
  3. 任意入力欄に質問を入力して送ると、そのチャットの続きとして質問できます。

9.3 新しいチャットを始める

  1. 必須1 新規チャット を押します。右側が「何をお調べしますか？」の初期表示に戻ります。
  2. 質問を送ると、新しい項目として履歴欄に追加されます。

9.4 履歴を削除する

  1. 任意履歴欄の項目にマウスを重ねると、右端に 3 × が表示されます。× を押します。
  2. 「このセッションを削除しますか？」の確認が表示されます。OK を押すと削除されます（キャンセル でやめられます）。
  3. 一覧から消えれば完了です。削除した履歴は元に戻せません。
表示・状況対処
「メッセージ取得に失敗しました」もう一度項目を押してください。改善しない場合はページを再読み込みしてください。
「セッション削除に失敗しました」少し待ってから再度お試しください。
「指定されたセッションを開けませんでした」リンクなどから開いたチャットが存在しないか、自分のものではありません。履歴欄から開き直してください。
履歴欄に「読み込み中...」のまま表示されないページを再読み込みしてください。
