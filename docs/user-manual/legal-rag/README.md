# 法令RAG 取扱法令一覧（利用者共有用）

法令RAGの対象カタログを利用者向けにまとめたPDFと、再生成用スクリプトをこのディレクトリでGit管理します。

- [取扱法令一覧PDF（2026-10-15版）](法令RAG_取扱法令一覧_2026-10-15.pdf)：4ページ、6分野・53法令。各法令名にe-Gov原文リンクを設定。
- [生成スクリプト](build_pdf.py)：対象カタログと法令一覧CSVを照合してPDFを生成。
- [対象カタログ（範囲・選定根拠の正本）](../../features/development/legal-rag-target-laws.md)
- [法令RAG設計](../../features/development/legal-rag-design.md)

一覧の基準日は2026-10-01、資料作成日は2026-10-15です。最新developの対象カタログ（選定説明の検証日2026-10-09）を参照しています。初期候補の根拠には確認記録がありますが、正式な対象部門の承認や本番利用の承認とは区別します。稼働環境の最新の収録状態と最新改正は未照合です。

## 更新手順

1. 対象範囲・選定根拠を変更する場合は、先に対象カタログを更新し、必要な共同確認・決定記録を行います。
2. 生成スクリプトの資料作成日・文書版・一覧基準日・説明文を更新します。対象件数や入力CSVを変更した場合は、件数検証と期待ハッシュも根拠を確認して更新します。
3. リポジトリルートで次を実行します。

   ```powershell
   .\venv\Scripts\python.exe docs/user-manual/legal-rag/build_pdf.py
   ```

4. PDF全ページの表示、全法令の名称・施行日・リンク、対象件数を確認します。READMEのPDFリンク・版情報・検証日も更新します。
5. PDFと生成スクリプト、関連文書の差分を同じ文書更新PRに含めます。

生成にはPython、ReportLab、日本語フォント（現状はWindowsのBIZ UDPゴシック）を使用します。上記は既存のローカル仮想環境での実行例です。別環境ではReportLabが利用可能なPythonとフォントパスを指定してください。

## 配布マニュアルとの書式統一

[利用者マニュアルのHTML](../eleknowledge-user-manual.html)と配布PDFをデザインの参照元とします。BIZ UDPゴシック、本文10.5pt・表9.8pt・補足9pt、青い左罫線と淡い青の章見出し、下線付きの節見出し、淡い青の表見出しとグレーの格子罫線、上部の文書名・版情報、中央の「ページ / 総ページ数」を合わせています。

法令一覧の分野別構成と4ページ構成は維持し、表紙・目次は追加しません。書式の変更に伴う法令名・収録版・原文URL・対象範囲の変更はありません。

PDFはGit履歴で旧版を追跡できます。更新時は旧ファイルを`git mv`で新しい日付のファイル名へ移し、スクリプトの出力名も合わせます。プレビュー画像は生成物確認用の一時ファイルとし、管理対象には含めません。
