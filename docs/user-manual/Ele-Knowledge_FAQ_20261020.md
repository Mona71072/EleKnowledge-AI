# Ele-Knowledge 利用者向けFAQ

第1版　2026年10月20日

Ele-Knowledgeの使い方や、困ったときによくある質問をまとめています。

## 利用・検索について

### Q1．使い方はどこを見ればよいですか。

利用者マニュアルをご確認ください。アカウント作成・ログイン、質問の送り方、絞り込み、原資料の確認、フィードバック、法令チャットの使い方を掲載しています。最新版のマニュアルは各課キーマンにお問い合わせください。

### Q2．AIの回答をそのまま業務判断に使ってよいですか。

回答は判断材料として利用し、判断する前に根拠となる原資料を確認してください。技術資料は「該当頁候補」「参考資料」からPDFを、法令は「参考資料」からe-Gov原文を開きます。適用条件や版も確認してください。

### Q3．うまく検索できないときはどうすればよいですか。

質問に機種・部位・状況などを補って再質問してください。絞り込みが強すぎる場合は条件を見直します。別の話題に移る場合は「新規チャット」を使います。解決しなかった結果は「解けない」から理由・補足を送ってください。

### Q4．「解けない」には何を書けばよいですか。

該当する理由を選び、必要に応じて補足を記入してください。「探した資料が候補に出なかった」「資料は出たが要約が違った」「知りたかった条件が抜けていた」など、具体的な内容が役立ちます。補足は200字までです。

### Q5．画面や機能の改善要望はどこへ送ればよいですか。

チャット画面の「こうなってほしい」から送信してください。回答が役立ったかどうかは、回答下の「解けた／解けない」で評価できます。質問箱のために同じ要望を再入力していただく必要はありません。

## 困ったとき・資料について

### Q6．法令はすべて検索できますか。

すべての法令を検索できるわけではありません。法令チャット（プレリリース）は、現時点で6分野・53法令を取扱対象としています。法律・施行令・施行規則・省令等をそれぞれ1件として数えています。対象法令と収録版の詳細は「法令RAG 取扱法令一覧」をご確認ください。最新版の一覧は各課キーマンにお問い合わせください。

### Q7．過去のチャットはいつまで残りますか。

各メッセージは作成から約60日で自動削除されます。追質問しても、古いメッセージの保存期限は延びません。RAGチャットと法令チャットの履歴は、それぞれの画面から開きます。

### Q8．資料のPDFが開けない、AccessDeniedと表示される場合はどうしますか。

チャット画面へ戻り、資料名を押して開き直してください。PDFを表示したタブのURLは発行から約5分で無効になります。開いたタブのURLを他の人へ送らず、共有したい資料名を伝えてください。

### Q9．ログインできない・利用できない場合の連絡先はどこですか。

まず利用者マニュアルの3章・10章の対処を確認してください。解消しない場合はEle-Knowledgeサポート（b_ele-knowledge-support@meltec.co.jp）へ連絡してください。発生日時、行っていた操作、表示されたメッセージを添えると確認しやすくなります。パスワードや確認コードは送らないでください。

## 質問箱について

### Q10．質問箱とフィードバックはどう使い分けますか。

質問箱は、使い方、登録資料、資料追加などについて、開発側に確認したいときの窓口です。回答が役立ったかどうかは「解けた／解けない」、画面・機能の改善要望は「こうなってほしい」をご利用ください。迷った場合は質問箱へご相談いただいて構いません。

### Q11．質問は誰から回答されますか。全員に公開されますか。

開発側で内容を確認し、必要な担当者と相談のうえ、ご本人へ回答します。使い方など、利用者に共通する内容は個人・現場が特定されない形に整理してFAQへ掲載する場合があります。質問の原文や個人情報をそのまま公開することはありません。掲載に配慮が必要な場合は質問本文に記載してください。

### Q12．いつ回答が来ますか。急ぎの連絡も質問箱でよいですか。

回答時期は確認内容によって異なります。急ぎの障害・利用できない状況は、質問箱の回答を待たず、利用者マニュアル記載のサポートへ直接連絡してください。
