# キーマン向け資料

キーマンへの共有資料と、開発側・キーマンで使用する質問箱Forms原稿を保管します。利用者向けFAQ・マニュアルは既存の [user-manual/](../user-manual/README.md) にまとめています。

## 採用版

| 資料 | 用途 |
| --- | --- |
| [2026年10月15日打合せ議事録（Word）](Ele-Knowledge_キーマン打合せ_議事録_20261015.docx) | 参加者による修正と、工事区分ごとの会議開催案・Formsによる賛否確認の追記を反映した版 |
| [質問箱Forms原稿（Word）](Ele-Knowledge_質問箱Forms_20261020.docx) | 利用者が修正した4項目を採用し、設問番号・入力例を整理した転記用原稿 |
| [質問箱Forms原稿（Markdown）](Ele-Knowledge_質問箱Forms_20261020.md) | 原稿の確認・差分レビュー用 |

Forms原稿には開発側の運用メモも含みます。文書全体を一般利用者へ配布せず、Formsへは案内文・設問・送信完了文を転記します。質問箱と、会議開催方針の賛否確認アンケートは別に扱います。Forms本体の作成・公開は今回の資料整理に含みません。

## 各課への展開

開発側とキーマンが参加するTeamsのチームで最新版のマニュアル等を保管し、キーマンから各課へ案内します。一般利用者が同チームへアクセスできる前提のリンクはFAQに掲載しません。

利用者へ配布する [FAQのPDF](../user-manual/Ele-Knowledge_FAQ_20261020.pdf) は `docs/user-manual/` にあります。キーマン活動・会議運営に関する質問は一般向けFAQに掲載せず、個別に受け付けます。

会議向けに準備した説明・検討資料は [開催日別の会議資料](../meetings/README.md) に分けています。[2026年10月15日の準備資料](../meetings/2026-10-15/README.md) から、本フォルダーの議事録へリンクしています。

## 今回の整理範囲

- FAQは公開版・書式統一版、議事録は開催日訂正と会議方針の追記済み版、Formsは整理版を採用しました。
- 作成過程の未採用版12ファイルと確認用画像7ファイルは、2026年10月20日の利用者の依頼に基づきローカルから削除しました。元ファイルは未追跡だったため、PR全体は採用版の追加差分です。
- 採用した配布資料は `meeting-materials/distribution/` から移動しました。10月15日向けの会議準備資料4ファイルは `docs/meetings/2026-10-15/` へまとめています。既存マニュアル・法令一覧、過去の検証記録は移動していません。
- アプリ・API・AWS設定・業務対象は変更していません。会議方針案を採択済みに変更するものでもありません。
