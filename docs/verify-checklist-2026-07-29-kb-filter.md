## 機種フィルタ（全機種共通の拾い方）

- [ ] **空欄 `model_type` の扱いを本番 KB で確認する**
  - コードは機種指定時に `選択機種 OR * OR general OR equals ""` を送る
  - **注意:** Bedrock の `equals: ""` は、メタデータにキーがあり値が空文字のときだけ拾える
  - **キー欠落（属性未設定）の文書は `equals ""` では拾えない**可能性がある
  - 確認方法の例:
    1. カタログで `model_type` 空欄の据付基準（例: `SUE-1-01`）を1件選ぶ
    2. 機種を指定して検索し、その資料が候補に出るか見る
    3. 出ない場合 → S3 の `*.metadata.json` で `model_type` が空文字かキー欠落かを確認
    4. キー欠落なら取り込み側で `""` または `*` を明示する／フィルタ方針を見直す

- [ ] 機種指定時に `*`（C資料の全機種共通）も候補に残ること
- [ ] `AXIEZ` 部分一致で `AXIEZ-LINKs` / `MAXIEZ*` が混ざる挙動を現場が許容できるか（必要なら厳密一致を別途）
