# 決定記録: 取扱機種スコープ（HANDLED_MODEL_TYPES 27値）2026-08-21

> **この文書の位置づけ:** RAG 検索の対象を「サービス提供部門が取り扱う機種の資料＋全機種共通資料」に限定する**取扱機種スコープ**（`HANDLED_MODEL_TYPES` 27値・UI 絞り込み6項目）の決定記録。PR #35 の「業務スコープ変更の共同確認ゲート」の対象。実測値はすべて 2026-08-26 確認時点の実環境スナップショット（正本: `docs/verification-2026-08-26-kb-vqv-metadata.md`）。

---

## 1. 決定

| 項目 | 決定内容 |
|---|---|
| スコープ | 検索対象 = `HANDLED_MODEL_TYPES` 27値のいずれかを含む機種固有資料 ＋ 全機種共通資料（`*` / `general`） |
| 適用方法 | 機種未指定でも post-filter で取扱外の機種固有資料を除外。機種指定時は UI 6項目 → 対象機種の `listContains`（要素完全一致）を検索前フィルタに適用 |
| UI | 絞り込みチップは 6 項目（AXIEZ / AXIEZ-LINKs / NEXCUBE / メルシティ / メルワイド / エスカレーター）。カタログ全機種の提示や部分一致の説明はしない（PR #64 で是正） |
| 位置づけ | **暫定処置**。恒久対策は KB メタデータへの `model_code` 付与（issue #53 で KB 所有側へ依頼中） |

## 2. 決定者・経緯

| 項目 | 内容 |
|---|---|
| 決定者 | YUKI ITAI（itai） |
| 決定日 | 2026-08-21（初回指定。同日中に駅舎エレを追加し **27値** で確定） |
| 実在確認 | 2026-08-26 の全数実測で 27値すべてが KB 実データに存在することを確認 |

**選定根拠:** サービス提供部門の初期業務スコープ（新設工事）で取り扱う機種。KB（据付資料バケット）には取扱外機種（NEXIEZ 系・モダニ系・ホームエレベーター等）の資料も含まれており、検索ノイズと誤案内の原因になるため、取扱機種に限定する。機種名リストは業務側の正式な機種棚卸し（model_code 語彙統制）が未整備のため、KB の `model_type` 実測 175 種から取扱対象を itai が指定した暫定リストであり、棚卸し完了時に置き換える。

## 3. 影響件数（2026-08-26 実測・全3,745件）

| 判定 | 件数 | 割合 |
|---|---:|---:|
| 検索対象（共通 `*` / `general`） | 819 | 21.9% |
| 検索対象（取扱機種を1つ以上含む） | 2,459 | 65.7% |
| **検索対象 計** | **3,278** | **87.5%** |
| **スコープ対象外** | **467** | **12.5%** |

対象外 467件の内訳 = 据付場用図 352 ＋ C資料 110 ＋ **W資料 5（全件）**。主な機種は NEXIEZ-MRL Version 2（392）ほかモダニ・保守系。全リスト: `docs/rag-model-filter-mapping-2026-08-26.md` §2/§5（PR #54）。

## 4. 対象外データの扱い

- **検索対象から外すのみ。S3 / KB からは削除しない**（mona と合意済み）。資料・メタデータ・索引には手を加えない。
- スコープ拡大（§6）した時点で、対象外だった資料はコード変更のみで検索対象に戻る。

## 5. 既知の副作用

- **W資料 5件は全件スコープ対象外**となり、カテゴリで W資料 を選んでも 0 件になる。このため UI の `w_doc` チップは業務判断が出るまで非表示（PR #57）。対応候補 = W資料機種（GPM 等）の `HANDLED_MODEL_TYPES` への追加 or W資料カテゴリのスコープ例外化（業務判断待ち）。

## 6. 見直し条件

次のいずれかが起きたら本スコープを見直し、変更する場合は本決定記録を更新する（PR #35 のゲート運用に従い、選定根拠・決定者・影響件数・対象外データの扱いを更新して共同確認する）:

1. 業務スコープの拡大（モダニ工事・空シ工の取扱開始）
2. KB 所有側による `model_code` 付与・語彙統制の完了（issue #53）→ 恒久方式（model_code ベース）へ移行し本暫定リストを廃止
3. 業務側の機種棚卸しの完了（取扱機種の正式リスト確定）
4. W資料の扱いの業務判断確定（§5）
5. KB の `model_type` 語彙の大きな変更（実環境変更後は影響項目を再確認する）
