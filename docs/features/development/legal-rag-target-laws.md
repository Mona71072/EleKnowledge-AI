# 法令RAG 対象法令フォルダ一覧

## 1. 位置づけ

法令RAGの初期取得対象を、e-Gov XML一括ダウンロード後のフォルダ名で管理するカタログである。

- 基準日: 2026-10-01
- 入力: [all_law_list.csv](../../../legal/all_xml/all_law_list.csv)
- 入力CSV: 10,689行（データ行）、SHA-256 `78A9BDFD2DD7DF7B83B64AF69B40BF12255E7FE8BEB222F83AC29532247FD65C`
- 収録条件: `未施行`が空欄の現行版
- フォルダ名: e-Gov本文URLの`/`区切りを、解凍後の`_`区切りへ変換した値
- 件数: 53フォルダ
- 未施行版・過去版: 本一覧には含めず、manifestで履歴管理する

## 2. フォルダ名の形式

```text
<元法令ID>_<施行日>_<改正法令ID>
```

例:

```text
322AC0000000149_20250601_504AC0000000068
```

この例は、昭和22年法律第149号について、令和4年法律第68号による改正を2025年6月1日施行として反映した版を示す。

### 2.2 対象外・保留データの扱い

- CSVの`未施行=○`の版と過去版は、この現行法令一覧には含めない。削除せず、取得・版管理上保持する場合も現行法令検索から除外する。
- 対象領域に直接対応しない法令は初期候補に選んでいない。ただし元CSVを再入手できないため、全ての除外法令と個別の除外理由を監査可能な形で特定できていない。業務側が必要性を示した法令は再評価する。
- 国土交通省・消防庁の告示、通知、通達、自治体条例、JIS、業界標準、メーカー資料は国の法令一覧CSVとは別ソースであり、この53件に含めない。法令とは法的性質・拘束力・利用条件が異なるため、同じ対象群に含めず、所管・対象地域・利用条件を確認した上で追加判断する。
- 対象外データは保持し、初期PoCでは検索対象に加えない。明示的な業務合意なしに削除しない。
