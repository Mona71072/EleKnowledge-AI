# 法令RAG 対象法令フォルダ一覧

## 1. 位置づけ

法令RAGの初期取得対象を、e-Gov XML一括ダウンロード後のフォルダ名で管理するカタログである。

- 基準日: 2026-10-01
- 入力: [all_law_list.csv](../../../legal/all_xml/all_law_list.csv)
- 入力CSV: 10,689行（データ行）、SHA-256 `78A9BDFD2DD7DF7B83B64AF69B40BF12255E7FE8BEB222F83AC29532247FD65C`
- 収録条件: `未施行`が空欄の現行版
- フォルダ名: e-Gov本文URLの`/`区切りを、解凍後の`_`区切りへ変換した値
- 件数: 53フォルダ
- 未施行版・過去版: 本一覧には含めず、manifestで履歴管理する

## 2. フォルダ名の形式

```text
<元法令ID>_<施行日>_<改正法令ID>
```

例:

```text
322AC0000000149_20250601_504AC0000000068
```

この例は、昭和22年法律第149号について、令和4年法律第68号による改正を2025年6月1日施行として反映した版を示す。

### 2.1 初期53法令の選定根拠（共同確認用候補）

> 最終検証: 2026-10-06 — 利用者提示の業務領域と`legal/all_xml/all_law_list.csv`（10,689行、SHA-256は§1参照）を照合。53フォルダすべてがCSV内の未施行でない版と一致。業務部門の正式選定資料は未確認であり、共同承認前の候補として記載。

この一覧は、昇降機の設置・建築、据付作業、電気工事、建設・改修・撤去、搬入に関する質問に法令根拠を提示するPoC候補である。法令を網羅した公式リストではなく、検索対象としての業務適合性もmona・itaiおよび対象業務部門の共同承認待ちである。

選定時に使った根拠と処理は次のとおり。

- 対象業務領域は、利用者が2026-10-01に提示した「エレベーターの設置・建築」「据付作業中の労働安全」「電気設備・電気工事」「建設業・環境・搬入」の4領域。
- 入力一覧はリポジトリ内の[`legal/all_xml/all_law_list.csv`](../../../legal/all_xml/all_law_list.csv)。`未施行`欄が`○`でない現行版候補を抽出し、法令名を対象領域に照合した。現行カタログ53フォルダはCSVの該当版53件と全件一致し、法令ID・施行日・改正法令IDを含むフォルダ名から再照合できる。
- 法律だけでなく、対象業務の義務・手続・技術要件を具体化する施行令・施行規則・技術基準省令も同じ対象群に含めた。
- 作業の発生・使用物質・設備などによって適用される法令は、通常対象と混同しないよう条件付き対象とした。
- CSVはe-Gov一括ダウンロードに付属する法令一覧としてリポジトリに保管する。取得日時はファイルから独立確認できないため、将来更新する際は取得日・取得元・SHA-256を記録する。一覧外の全法令について個別の除外理由を示すことは未完了。

### 2.2 対象外・保留データの扱い

- CSVの`未施行=○`の版と過去版は、この現行法令一覧には含めない。削除せず、取得・版管理上保持する場合も現行法令検索から除外する。
- 対象領域に直接対応しない法令は初期候補に選んでいない。ただし元CSVを再入手できないため、全ての除外法令と個別の除外理由を監査可能な形で特定できていない。業務側が必要性を示した法令は再評価する。
- 国土交通省・消防庁の告示、通知、通達、自治体条例、JIS、業界標準、メーカー資料は国の法令一覧CSVとは別ソースであり、この53件に含めない。法令より下位・上位の資料と一括して扱わず、利用条件・対象地域・所管を確認した上で追加判断する。
- 対象外データは保持し、初期PoCでは検索対象に加えない。明示的な業務合意なしに削除しない。

### 2.3 共同確認・決定記録の状態

本節は選定経緯の説明であり、業務スコープの承認記録ではない。現時点で決定・記録が必要な項目は次のとおり。

| 項目 | 状態 |
|---|---|
| 初期候補と選定理由 | 上記のとおり提案。正式な対象業務・対象部門との照合待ち |
| 元CSVの保管場所・取得日時・ハッシュ | 保管場所とSHA-256は記録済み。取得日は未記録 |
| 決定者・確認者・決定日 | 未確定。mona・itaiおよび必要な業務側確認者の明示確認が必要 |
| 追加／除外対象と影響件数 | 現行候補53フォルダ。正式承認後に変更差分と利用者影響を記録する |
| PoC利用者範囲・見直し責任者・期限・終了条件 | PR #155の共同確認事項として未決。別途明示合意を記録する |

したがって、このカタログは開発PoCの候補とその説明資料であり、単独では検索対象追加の承認、過去のdev利用の遡及承認、または本番利用の承認を意味しない。追加・除外・利用範囲の決定は、必要な共同確認と明示合意を記録してから反映する。

## 8. 取得時の注意

- 本一覧は2026-10-01時点の現行版スナップショットである。
- 将来施行版は`未施行=○`として別管理し、現行RAGには登録しない。
- 同じ法令IDでも施行日・改正法令IDが異なる版は別フォルダとして扱う。
- 取得後はXMLのSHA-256、取得日時、本文URLをmanifestへ記録する。
- 法令の対象範囲を追加・除外する場合は、業務部門の共同確認と決定記録を行う。
- 国土交通省・消防庁の告示、通知、通達、自治体条例、JIS、業界標準は本一覧に含まない。

## 9. 初期候補の根拠と共同確認

> 最終検証: 2026-10-02 — 2026-10-01の設計会話、e-Gov対象一覧、PR #155へのMonaレビューを照合。共同承認の記録は未完了。

### 初期候補の選定根拠

- 2026-10-01の会話で、利用者がe-Gov一括取得を開発時の初期取得手段とし、昇降機の設置・建築、据付時の労働安全、電気設備・電気工事、建設・環境・搬入に関する質問を対象候補として提示した。
- 会話中に提供された`all_law_list.csv`から、`未施行`が空欄の現行版フォルダを抽出した53件を初期候補とした。フォルダ名は元法令ID・施行日・改正法令IDを保持する。取得元は[e-Gov XML一括ダウンロード](https://laws.e-gov.go.jp/bulkdownload/)である。
- この53件は初期PoC候補であり、昇降機業務に必要な法令を網羅した公式リスト、または所有部門が選定した正式リストとは確認できていない。元CSVは会話時の一時ファイルで、現在リポジトリにもローカルTempにもないため、53件の選定を独立再現できる原資料の保管は未完了。

### PoCの境界

- 初期候補は本書の現行版53フォルダ。昨日の実装依頼時点で追加・除外した法令はない。
- 未施行版・過去版・一覧外の法令、および告示・通知・自治体条例・JIS・業界標準は、削除せずローカルに保持し、今回のアップロード・検索対象に含めない。これらを対象へ加える際は別途選定理由と業務影響を確認する。
- PoCは開発環境 `ap-northeast-1` に限定し、通常RAGと本番には適用しない。法令カードとAPIの両方に開発用機能ゲートを設け、既定OFF・本番OFFとする。テスト利用者の識別方法と許可対象は未決のため、許可対象が合意・設定されるまで法令モードを有効化しない。
- 所有部門との会話について、itaiは2026-10-01に「既存メタデータキーは変更せず、新規キー追加は可能との許可を得た」と報告した。許可した担当者名や承認記録は昨日の会話に残っていない。この確認はメタデータ変更の許可であり、検索対象53法令の業務スコープ承認とは区別する。
- 同日「口頭で実装OKを得た」との発言があるが、承認者は会話記録から特定できないため、Monaや所有部門の承認として記録しない。MonaはPR #155で選定根拠・対象利用者・費用・見直し条件等の決定記録が揃うまでNoと回答している。したがって、本カタログは共同承認済みの決定ではない。

### 共同確認に残る決定

- 正式な選定根拠（対象部門・対象業務、一覧の原資料、対象外とした法令・理由）と、業務側の決定者・確認者名を記録する。
- 開発用KBの概算費用、月額上限、PoC終了時の停止・リソース片付け条件を、KB作成・初回Sync前に合意する。昨日の会話では費用上限と終了条件は決まっていない。
- PoCの見直し責任者・期限・終了／拡大条件を決める。昨日の会話では責任者名と期限は決まっていない。
- 上記の合意が記録されるまで、法令専用KBの新規作成・初回Sync・実利用へ進まない。既に開発バケットに保存済みの公開法令データは保持し、削除しない。
