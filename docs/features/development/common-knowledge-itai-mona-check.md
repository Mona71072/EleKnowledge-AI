# 共通知識: mona の動作確認手順（itai 環境）

> 最終検証: 2026-10-22 — itai 配信（`554d9673`）と認可表の割当を前提に作成。mona の権限付与後に PR #195 で連絡する。

itai 専用 AWS 環境に置いた共通知識（ノウハウ＋用語・基礎知識）を、mona のアカウントで画面確認するための手順です。背景と実施記録は [実装契約](common-knowledge-itai-aws-contract.md)の「S3正本化への改訂」「S3正本化の反映と受入」節、決定事項は [引継ぎ](common-knowledge-itai-s3-canonical-handoff.md)にあります。

## 前提

| 項目 | 内容 |
| --- | --- |
| 開く場所 | Amplify itai ブランチの配信 URL（Amplify コンソールの itai ブランチに表示）。ログインは普段の dev と同じ Cognito アカウント |
| mona の権限 | 検証範囲 `itai-validation` の **閲覧・公開版の読取だけ**。投函・編集・承認・公開・停止はできない（押すと「この操作は許可されていません」）。期限 2026-11-05 |
| 入力してよい内容 | 合成の内容だけ。実資料・個人情報は入力しない |
| つながる先 | itai 環境の RAG・チャット・先輩チャット・共通知識は itai 専用 API。共有 dev のデータ・設定は使わない（チャット履歴は itai 専用で、dev の過去の会話は出ない） |
| 権限の判定 | Cognito の admin 所属ではなく、itai 専用の認可表で決まる。admin でも認可表になければ何もできない |

## 確認手順

1. ホームに「ノウハウ・用語と基礎知識（検証中）」カードがあること → 開く。
2. 「権限を確認」→ 業務権限が「閲覧・公開版の読取」、分野 `itai-validation`、共有許可・根拠台帳が「なし」と出ること。ボタンのすぐ下に緑の「完了」表示が出ること。
3. 候補の状態を「正本反映済み」にして「共有一覧を取得」→ 検証で作った候補が 1 件出ること。選ぶと要約・文脈と、単元 `KH-ITAI-VAL-1` の作業版（第4版・承認済み・承認束hash）が見えること。編集・承認・公開のボタンは出ないこと。
4. 「両AIと共通の公開版確認」で単元ID `KH-ITAI-VAL-1` →「公開版を毎回確認して読む」:
   - 停止中なら赤の「失敗: … (NotPublished)」。
   - itai が再公開している場合は本文と「第4版・公開世代N」が出る。
5. 参考（任意）: itai 環境の先輩チャット（ホームの「先輩チャット」カード、管理者限定）が itai 専用 API で動くこと。#195 の画面を itai の配信で確認できる。

## 見てほしい点

- 権限のない操作が画面に出ない／出ても API で拒否されること（admin でも拒否されること）。
- ボタンを押したときに、押した場所の近くで処理中・成功・失敗が分かるか。
- 読取が「公開中の版だけ」になっているか（停止後は読めない）。

## 結果の返し方

PR #195 のコメントで、手順番号ごとに「OK／NG（表示された文言）」を返してください。NG の場合、画面の赤い表示の `(コード)` 部分があれば原因を追えます。

## 権限を外すとき

検証が終わったら itai が認可表から mona の行を外します（または期限 2026-11-05 で自動的に無効）。共有 Cognito のグループは変更していません。
