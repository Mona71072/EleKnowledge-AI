## A. バリアフリー・円滑化

| | |
| --- | --- |
| **Lists** | **135**（全エレ）— 検査で何を見るか不明 |
| **カード** | [KH-ALL-BARRIER-FREE-INSPECTION-135](../cards/practice-guides/KH-ALL-BARRIER-FREE-INSPECTION-135.md) |
| **法令 RAG** | 円滑化法 `418AC…0091`、施行令 `418CO…0379`、規則 `418M6…0110`、誘導省令 `418M6…0114` |
| **OneNote** | `:39`（検査例・基準説明）、添付チェックシート（未コピー） |

### 現場向けまとめ（Lists 135 + OneNote :39）

1. **二つの基準**
   - **建築物移動等円滑化基準** — **義務**（一定規模以上の特別特定建築物など）。建築側がチェックシート提出。
   - **建築物移動等円滑化誘導基準** — **任意**だが、適合で容積率緩和・補助金等。
2. **エレ現場でよく見る項目**（OneNote 検査例・Lists「添付参照」）
   - かご内 **出入口高さ・幅**、**手すり高さ**
   - **到着階・戸閉アナウンス**、**車椅子用押しボタン高さ**
   - 他 profession のスイッチ高（例：照明 **1100 mm** 付近）も指摘例あり。
3. **開き方**
   - 条文 → dev **法令チャット**（上記 `law_id`）。
   - 検査項目表 → OneNote **:39** 添付 / Lists 135 添付（スナップショット外）。

## B. 建築基準法まわり（遮煙・昇降路・型式認定）

### B-1 遮煙ドア・大臣認定シール

| | |
| --- | --- |
| **Lists** | **346**（番号・金/銀シール）、**227**（遮煙＋火災管制＋MELD 必須）、**154**（シャフト内煙感知器） |
| **カード** | [346](../cards/practice-guides/KH-ALL-SMOKE-DOOR-SEAL-346.md) · [227](../cards/practice-guides/KH-ALL-SMOKE-FIRE-SERVICE-MELD-227.md) · [154](../cards/practice-guides/KH-MRL-SMOKE-SHAFT-DETECTOR-154.md) |
| **法令 RAG** | 建築基準法 `325AC…0201`、施行令 `325CO…0338`、規則 `325M5…0040` |
| **KB / 告示** | **S-31-50.1**（大臣認定・戸閉方式）。Lists: **109/112 条・平12年1360/1369 号**（遮炎）— **法令 RAG 外** |

**346 まとめ**

- 認定番号は **戸閉方式（CO / 2S / 2CO 等）** と三方枠・乗場戸仕様で分岐。
- **金シール＝特定防火設備** / **銀＝防火設備**（窓付きは防火側になりやすい。CAS-1046 (1)/(2) 等）。
- **非常用エレ** — 昇降路壁は耐火＋**特定防火（窓無）**（Lists: 129条の13の2）。

**227 まとめ（Lists のみ）**

- 遮煙乗場ドアを防火設備として成立させるには **火報連動火災管制運転** ＋ **MELD または戸閉保証用バッテリー盤**（大臣認定条件）。
- 火報盤が無いのに SW だけ「火災管制あり」→ **認定を満たさない** → 設計変更 or **認定シール撤去**。
- **自家発を遮煙戸の予備電源に代用不可** — 火災時給電・3 分以内起動の保証がないため。

**154 まとめ（Lists のみ）**

- 据付要領の「遮煙階ロビーに感知器」は **火災管制運転** の着床前火災対策（20 秒閉鎖の認定条件）。
- **昇降路に煙感知器必須**という建築条文ではない。**自火報（消防法）** がある建物では **竪穴警戒区域** に **1 種煙感知器**（火災感知器不可）。自火報義務が無ければ昇降路への設置義務も無い、という Lists 整理。
- 警戒区域: 600㎡以下・辺 50m 以下等。エレ昇降路は **縦方向の別区域**。

### B-2 昇降路内・突起物・配管・防火扉配線

| | |
| --- | --- |
| **Lists** | （単独 ID 少 — 豆知識・技評で散在） |
| **カード** | [昇降路索引](../cards/practice-guides/KH-ALL-SHAFT-INTERNAL-ROUTING.md) |
| **OneNote** | **:41**（短文）、**:42**（実務7項） |
| **法令 RAG** | 建築基準法・施行令（129条の7、129条の2の5、129条の13の3 等） |
| **告示（RAG 外）** | **1495号**（許容ブラケットの地震時措置）、**570号**（昇降路配管の 3 区分） |

**:42 実務要点**

- 昇降路は **不要な突起・無関係設備を原則禁止**。
- レールブラケット等は **例外として限定的許容** ＋ **1495号** の安全措置。任意突起の全面許可ではない。
- 配管は **エレ必要配管 / 導体なし光ファイバ / その配管** に限定（570号）。他設備幹線の昇降路通線は原則 NG。
- **防火扉配線** — 扉設備として必要でも、**昇降路縦配線ルートとして当然 OK ではない**。経路・最小接続・個別認定を確認。
- **非常用エレ** も昇降路ルールは緩和されない。

### B-3 型式認定・完了検査

| **OneNote** | **:44**（制度の全体像）、**:45**（規格型のみ取得例） |

- 型式適合認定 → 確認申請で **装置本体構造計算省略可**（建物構造は別）。
- 製造者認証 → **量産品質**。
- **使用前検査（完了検査）** は認定があっても **必須**。
- 大規模カスタムは認定コスト対効果が低く、取得例が少ない。

### B-4 セパ穴（:43）

- **非貫通・昇降路へ飛び出していない** セパ穴を、建築基準エレ条文だけで「必ず充填」と断言しにくい。
- 埋めろ要求は **公共建築工事標準仕様書**（品質・仕上げ）由来のことが多い。
- 検査側に **どの条文・告示か** を特定させるのがよい（129条の7は **突出物**）。

## C. 消防法（放送・自火報）

| | |
| --- | --- |
| **Lists** | **122**（2/3 線式）、**154**（上記 B-1） |
| **カード** | [122](../cards/practice-guides/KH-ALL-BROADCAST-2-3-WIRE-122.md) |
| **法令 RAG** | 消防法 `323AC…0186`、施行令 `336CO…0037`、規則 `336M5…8006` |

**122 まとめ**

- **2 線式** — 同一信号線で放送。**3 線式** — 信号線が分離。
- **非常放送**で **音量調整機器（BGM 操作盤 SW＋アッテネータ）** を付ける場合 → **3 線式必須**（Lists: 消防法・施行規則25条の3）。
- **2 線式＋非常放送** → 操作盤内 SW **不可**。三菱方針でアッテネータ推奨なら **2 線時はアッテネータ外す** 必要あり。
- **施工例** — 地上 **11 階以上** または地下 **3 階以上** で非常放送設備義務（Lists Notes）。

## D. 労働安全衛生・落成検査（構造規格）

| | |
| --- | --- |
| **Lists** | **278**（SfleX・非対称ソケット） |
| **カード** | [278](../cards/practice-guides/KH-MR-SFLEX-ROPE-SOCKET-278.md) |
| **法令 RAG** | 労働安全衛生法 `347AC…0057`、施行令 `347CO…0318`、規則 `347M5…0032` |
| **告示（RAG 外）** | **エレベーター構造規格**（平成5年労働省告示91号 等）— 29条端末、40条ロープ性能 |

**278 まとめ**

- **落成検査**は **建築基準 OK でも** **構造規格（安衛・告示）** 目線で指摘あり得る。
- **コッタ止め** — 構造規格29条図は **対称ソケット**。**非対称**は愛知労基へ解釈確認 → OK 回答（Lists）。
- **SfleX-rope** — 非対称くさびの労基承認あり。SfleX 自体の **JIS3525 以上相当** も労基へ確認 → OK 解釈（Lists）。
- **現場** — SfleX 時は回答資料添付必須。普通ロープも労基要求時は同資料可。

**OneNote :38（吊具安全率）** — クレーン則213・214を引用し、エレつり **安全率 5 以上**で計算、と整理。

## E. 条例・都道府県（53法令外）

| **Lists** | **331** — HYOG + DKO-TR 重複時、トランク扉 SW 不要 |
| **カード** | [331](../cards/practice-guides/KH-ALL-HYOGO-TRUNK-SW-331.md) |

**331 まとめ（Lists）**

- 条例仕様で **専用運転（キーで戸開維持）** 可 → トランク扉 SW の **30 秒戸開延長（DKO-TR）** と実質重複 → **SW 不要** という社内整理。
- 根拠は **S-1-B120(3)**、**JEAS-A514C**（専用運転選択）等 — **条例本文は法令 RAG に無い**。案件ごとに設計・規格確認。
