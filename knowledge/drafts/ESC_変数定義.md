# エスカレーターのトラス変数一覧

| HE | 製作階高 |

| FJ | 上部トラス深さ |

| LL | 上下支点間水平距離 |
| NJ | 上部ニュアル長さ |
| NK | 下部ニュアル長さ |
| TG | トラス全長水平寸法 |

| TK | 下部トラス長さ |
| SUJ | 上部支持アングル長さ |
| SUK | 下部支持アングル長さ |
| RA | 下部支点荷重 |
| RB | 上部支点荷重 |

| LC | 中間支点間水平距離 |
| LD | 中間支点間水平距離 |
| SC | 中間サポート高さ |
