# u形エスカレーター CSS点検記述

## 機能・設置

原文では、ステップとコムプレート間の異物挟まれを検出し、エスカレーターを停止する安全装置と説明されている。上下左右のコムプレートに1箇所ずつ、計4箇所設置と記載されている。

## 原文記載の点検値

- バネキャップとワッシャ間: 2±0.3 mm。隙間が平行でない場合は最も狭い箇所で判断。
- スイッチと作動片間: 0.2-0.5 mm。
- コムスカート下端とサイドローラー上面: 接していないこと。設計値3.7 mm。
