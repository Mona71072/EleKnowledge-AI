# u形エスカレーター CRSの乗降口側点検記述

## 原文記載値

| 項目 | 原文値 | 条件 |
| --- | ---: | --- |
| 出口作動レール高さ H1 | 79±1 mm | 上下部共通との記載 |
| 入口作動レール高さ H2 | 78 mm以上 | 上下部共通との記載 |
| スイッチと作動片の間隙 J | 0 < J <= 0.5 mm | 原文記載 |
| 動作荷重 | 100±10 N | 原文記載 |
| ストッパー部隙間 | 6±0.5 mm | 検査ノート本文の記載 |

## 未解決の資料間差分

原文ノートは、施工要領書P.388には上部6±0.5 mm・下部6.5±0.5 mm、検査基準とC資料には上部・下部とも6±0.5 mmと記載されていると報告している。リンク先資料は未閲覧であり、どの値が適用されるか判断していない。担当者が承認済み最新版を照合するまで、値を統一・選択しない。
