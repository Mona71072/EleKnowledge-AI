# エスカレーターのトラス固定記録に関する確認事項

## 原文に記載された運用

- 品質管理業務マニュアルからの引用として、品質管理部門がトラス固定完了報告書を確認・検認し、エスカレーター工事完了試験報告書等と一緒に保管すると記載されている。
- 同じ引用に記載された保管期限は10年。
- 原文は、2011年の東日本大震災でトラスが落下した重大事故を受け、トラス掛かり代の実測寸法と施工写真を記録する運用としている。
- 参考資料としてTI-858および両端非固定対応のトラス固定要領書を挙げている。
