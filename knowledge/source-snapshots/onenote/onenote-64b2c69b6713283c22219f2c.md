**Method to Reset Error Code 63A for detecting Non-Recommended Procedures with car-top work.**

Starting from production 25/5B, a safety enhancement function has been added for car-top operations.

This function may be activated after you perform Non-Recommended Procedure such as stop the running car by opening landing door in NORMAL (automatic) operation to ride on the car-top. This function shows error code 63A, prevent car movements and sound a buzzer. If this error occurs accidentally, reset it using the following procedure.

<u>1-15-1) During Car-Top work</u>

① If in NORMAL (automatic) operation, switch to INSPECTION (manual operation).

② Turn off the car top RUN switch (#29).

Note: The order of steps ① and ② does not matter.

③ Turn on the car top RUN switch (#29).

<u>1-15-2)  After Completing Car-Top work</u>

① Turn off the RUN switch (#29).

② Open the landing door and switch to NORMAL(automatic) mode from the landing floor.

③ Turn on the RUN switch(#29) from the landing floor.

④ Close the landing door.

**How to clear error code 668,638** **text p.9**

Error code 668,638 is detected when startup is inhibited while a person is on top of the car or

during work.

The following procedure operates ETP on the top floor.

Procedure

①Set the ED/NOMAL selecter to ED

②Set the elevator car to B mode using the remoto control.

③Operate the remote control press "Start" → "3" → "2" → "OK".

④Shut off the power.

⑤Power on.

⑥Set the elevator car to A mode using the remoto control.

⑦Set the ED/NOMAL selecter to NOMAL.

**How to clear error code 63A** **text p.20**

Error code 63A is detected When ED is turned on while 29 is turn off.

The following procedure operates ETP on the top floor

Procedure

①Set the ED/NORMAL selector to ED.

②Move the cage away from the DZ.

③Open the landing doors.

④turn off 29.

⑤Set the ED/NORMAL selector to NOMAL.

⑥turn on 29.

⑦Close the landing doors.\n
