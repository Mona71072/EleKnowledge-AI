## OneNote content
統合調整運転

(1)内容

Content

①複数の調整機能をまとめて実施することができる。

Multiple adjustment functions can be performed collectively.

②統合調整運転は、２種類

There are two types of integrated adjustment operations:

統合調整運転A→ブレーキ関係の調整

Integrated Adjustment Operation A → Brake-related adjustments

（静的ブレーキトルク/動的ブレーキトルク（BK1/BK2）UCMP制動距離）

(Static Brake Torque / Dynamic Brake Torque (BK1/BK2) UCMP Braking Distance)

統合調整運転B→NLでの終端往復運転による調整

Integrated Adjustment Operation B → Adjustments by NL terminal round trip operation

（FMS/イナーシャ同定/TSDマージンチェック/TSDチェック（UP側のみ））

(FMS / Inertia Identification / TSD Margin Check / TSD Check (UP side only))

③UP方向のTSDチェックのみ実施するため、DN方向のみ別途確認する必要があるので注意。

Note that only the UP direction TSD check is performed, so the DN direction must be checked separately.

(2)目的

Purpose

①複数の調整機能をまとめて実施することができるため、高速調整の作業効率向上が見込める。

Since multiple adjustment functions can be performed collectively, an improvement in the work efficiency of high-speed adjustment can be expected.\n
