**1. Overview (概要)**

This procedure explains how to update the elevator software. The process differs depending on whether the on-site adjustment has already started, as existing adjustment data must be preserved.

（この手順ではソフトウェアのアップデート方法を説明します。調整作業がすでに開始されている場合、既存の調整データを保護する必要があるため、プロセスが異なります。）

**2. Scenario A: Before Adjustment has started (調整開始前の場合)**

If no on-site adjustment data exists, the process is straightforward:

1. **Check the old software version.**
1. **Read and back up the old software.**
1. **Write the new software.**
1. **Verify the new software version.**

**3. Scenario B: After Adjustment has started (調整開始後の場合)**

If adjustment data (e.g., pole matching data, NL/BL values) already exists, you must migrate this data to the new software:

1. **CPU Reset + HAND Mode:** Prepare the system for data handling.
1. **Memory Compare 1:** Identify and record existing adjustment data to be migrated to the new software.
1. **Write New Software:** Perform the software update.
1. **Verify Version:** Confirm the new software is correctly installed.
1. **Restore Adjustment Data:** Write the recorded adjustment data back into the system using a Maintenance PC.
1. **CPU Reset + HAND Mode:** This step is crucial to transfer the restored data from RAM to Flash ROM.
1. **Memory Compare 2:** Perform a final check to verify that all adjustment data has been correctly updated and applied.

NOTE:

Always perform "Memory Compare" twice when adjustment data exists to prevent the loss of site-specific parameters.

（注意：調整データが存在する場合は、現場固有のパラメータ消失を防ぐため、必ず2回のメモリコンペアを実施してください。）
