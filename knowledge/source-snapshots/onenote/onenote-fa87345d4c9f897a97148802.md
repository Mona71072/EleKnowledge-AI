## OneNote content
\[6\] Q&A Examples

Q1: Can S/W ver. 3.7 be used for MRL?

A1: If a software change is required for MRL, please use S/W ver. 3.8.

Q2: What should be done if a PC error occurs during software loading?

A2: Restart the loading process. If data is lost, you must obtain the original software and rewrite the adjustment parameters.

Q3: What should I do if the CWT balance is outside the ±0.5A range?

A3: Re-verify the amount of CWT weights. If it still does not meet the standard, request a traction calculation from Inazawa Works (Inaden) to confirm the allowable value.

Q4: The dynamic brake reference table (C-7-C3350.76) only goes up to 1000kg (PM016SR), but the GDRLE is 1050kg. What is the reference value?

A4: This was an update omission in the manual. The 14-person capacity is 1050kg in China, but 1000kg in other countries. (Since NEXIEZ was originally designed for markets outside China, the update was missed.) The reference value is the same as the 1000kg model.

Q5: Why is a higher value better for static holding power, while a lower value is better for dynamic brake torque?

A5: Static holding power represents the braking force as a percentage, so a higher value is better. Dynamic brake torque represents the amount of slip (sliding distance), so a lower value is better.

Q6: If the static holding power is below 180, will adjusting the brake gap change the torque value? Can torque be adjusted on-site?

A6: Brake gap and torque management are separate, so the torque value will not change. If the problem persists after following the instructions in the C-manual, be sure to contact Inazawa Works (Inaden) via a trouble report.

Q7: The TSD switch position list in the C-manual mentions "High Acceleration" and "Standard Acceleration." How do I determine which one to use from the parts list?

\[Background: During a test at the GDRLE tower, FMS failed with standard acceleration dimensions but succeeded after changing to high acceleration dimensions.\]

A7: High acceleration applies only to 2.5m/sec models for the Chinese market (to meet GB requirements). Therefore, any 2.5m/sec model for China should be treated as high acceleration. We recognize that this logic is not explicitly documented and intend to clarify the verification method.

Q8: What does FMS monitor? Does it look at 1USD or USR in addition to DZ plates? What is the allowable error for a successful FMS?

A8: FMS primarily monitors the DZ (Door Zone). However, since the car position is initially unknown, it uses 1USD and USR to correct the remaining distance while stopping at the terminal floor DZ. FMS completes if the car stops at the terminal DZ or detects UL/DL. If terminal switches are set too far forward, the car cannot stop at the terminal DZ, causing FMS to fail. If set too far back, it may overshoot the DZ without detecting UL, also causing failure. The "allowable error" is the range within which the car can successfully stop at the terminal DZ. Note that 1USD errors have little impact as the position is re-corrected by USR.

Q9: There is a function to check the dimensional error of USR and 1DSD. What values are these compared against?

A9: They are compared against the reference positions specified in the C-manual. In your case, even if the 1USD error was large, FMS likely succeeded because the USR was positioned well enough to allow the car to stop at the terminal DZ.

Q10: Regarding the parameter backup/return function (SET1/0=0/8, MON1/0=6/8): Why is this not in the C-manual, and is it valid for S/W ver. 3.8 without a Maintenance Tool (Mente-con)?

A10: This function was ported from VFGH, but it has not been officially evaluated for VFGLC. While it likely works (including for NEXIEZ-MRL without a Mente-con), we have not officially announced it because evaluation is pending. Please understand that we wish to complete evaluation before official announcement.

Q11: Can Flash Memory Ver. 3.8 back up all data areas?

A11: Yes, it can back up all areas. However, if the new software contains parameters in those areas, you must reflect the site-specific adjustment data into the new software. Use the maintenance program to perform a "Memory Compare." Both Flash Memory Ver. 3.8 and the maintenance program are required.

Q12: What does "Memory Compare" check?

A12: It checks for mismatches between factory default data and site-saved data. This includes critical adjustment data such as magnetic pole learning and weighing data. This must be performed to ensure proper system recovery if software loading/writing is interrupted.

Q13: Can any communication speed be set for software loading and writing?

A13: Available communication speeds vary by model. Please refer to the C-manual for the correct settings.

Q14: What should be done if the dynamic torque is outside the reference range?

A14: Inspect the brake area for oil or foreign matter. If clear, perform several E-stops to "bed in" (run-in) the brake. If it still doesn't meet the standard, submit a trouble report.

Q15: How should leveling be adjusted if errors persist even after using FSHFT?

A15: Adjust the physical position of the DZ plates. (Note: This is currently not in the NEXIEZ MR/MRL C-manual; please refer to domestic Japanese documentation for details.)

Q16: When selecting the target in the S/W Maintenance Module, why are there options for both VFGLC 8MB and 16MB?

A16: The P1 PCB was changed to double the ROM capacity.

Q17: How do I distinguish between VFGLC 8MB and 16MB?

A17: Check the suffix of the P1 PCB: A = 8MB, B = 16MB. If you cannot check the board, verify the parameters via MON1/0=F/7. (Example: If the result is "3" for GLPR113-A, it is VFGLC2, which is 16MB.)

Q18: Why is it sometimes impossible to switch to Independent (IND) or turn lights ON/OFF using the remote control?

A18: This depends on the EVRC settings. Available functions vary between settings 1 and 4. Refer to C-6-S1310.E Page 13 (Select COM "71" → "1" to "4").

Q19: What does "W.A." on the remote control stand for?

A19: It stands for "With Attendant" (automatic operation with an operator, often used in department stores). By using the "5" (PASS) key on the remote, the car can bypass hall calls.

Q20: What is the "BLSH" parameter listed in the data sheet?

A20: It is a counterbalance parameter. It is factory-set and does not require adjustment on-site.\n
