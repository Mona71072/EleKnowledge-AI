**【Reference information】**

| **Role of the DC-CT** |
| --- |
| The DC-CT detects current from the inverter and converter sections and sends the detection signal to the control board. The control board uses this signal to check whether the current is within the proper range and to perform current feedback control. The DC-CT also monitors whether the VVVF inverter is supplying proper current during high-speed IGBT switching operation. If the DC-CT detects -0.6 V or lower or +0.6 V or higher while the motor is stopped, error code “031” is displayed. Error 031: CT abnormality / DC-CT failure While the motor is stopped, the detected current should normally be near zero. However, electromagnetic noise, induced noise, zero-point offset, poor connector contact, or sensor circuit abnormalities may affect the DC-CT detection signal. If the control board incorrectly detects current due to these factors, error code “031” may be displayed. If the feedback value is detected incorrectly, excessive current may flow, which can cause vibration or abnormal operation. |\n
