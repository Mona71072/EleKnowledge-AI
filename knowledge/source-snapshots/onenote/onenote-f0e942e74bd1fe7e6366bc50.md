ROM＆RAM

RAM…RAM(Random Access Memory) is the working memory used by the CPU for data processing.

When the power is turned off, the data stored in RAM is also erased.

ROM…ROM(Read Only Memory) is a type of memory that allows only reading and does not permit

writing. Unlike RAM, its data remains intact even when the power is turned off. In the P1

board, parameters are stored in Flash ROM as the storage medium. Flash ROM refers to a

type of ROM that, exceptionally, allows data to be written.

When the P1 board is on the MNT side, resetting the CPU transfers the data from RAM to flash ROM.\n
