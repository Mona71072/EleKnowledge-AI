※ (OneNote reference (unresolved in snapshot): HGS (hand Gurd Safty Switch)|HGS)

ハンドレールインレットガードスイッチ(以下 HGS)は、手摺インレット部で異物が挟まれたときに

異常を検出してエスカレーターを停止する安全装置であり、全4カ所(上下部及び左右勝手)に設置される。

| ①動作圧；20±5N |
| --- |
| ②手摺とブーツの隙間；2.0mm以上(※奥側も同様に隙間がある事を目視にて確認する事) |
| ③ﾌﾞｰﾂ四隅のいずれを押した場合でもHGSが動作する事。 |
| ④エンドキャップより500mm程度の範囲で気配りｱﾅｳﾝｽ(OP)が動作する事。（屋外適用無） |

【装置概要】

1.解説

通常ブーツはバネにより外側に押し付けられ固定されている。

異物が移動手摺によりイントレット部に巻き込まれることにより、

ブーツが内側方向に押されスイッチが押されてエスカレーターが停止する。

動作荷重はバネ長によりコントロールする。
