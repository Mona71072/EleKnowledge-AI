1. 43.起動秤（WGHG）の調整

Start Weighing (WGHG) Adjustment

(1)作業内容

Work Procedure

①運転起動時（ブレーキ解放時）に起動ショックが発生する場合、パラメータ補正をかけ、起動ショックを解消させる。

If a starting shock occurs during operation startup (when the brake is released), apply parameter compensation to eliminate the starting shock.

(2)目的

Purpose

①運転時、ブレーキ開放→約0.5秒間ディスク停止→ディスク回転→約0.5秒間ディスク停止→ブレーキが閉じる

During operation: Brake release → Disk stops for approx. 0.5 seconds → Disk rotates → Disk stops for approx. 0.5 seconds → Brake closes.

②このブレーキ開放後のからディスクが動き出すまでの間に起動ショックが発生！！

A starting shock occurs during the period from brake release until the disk starts moving!!

③また、起動ショックの発生原因はカゴとオモリのアンバランスによる負荷とその負荷に対して逆側にトルクを掛ける起動秤補正値が噛み合ってないため起動ショックが起きる。

Furthermore, starting shock occurs because the load caused by the imbalance between the car and counterweight, and the starting weighing compensation value that applies torque in the opposite direction to that load, are not properly matched.

④例：NLでの走行時、動き出す前にUP方向に起動ショックが発生。

Example: During NL operation, a starting shock occurs in the UP direction before movement begins.

→DN方向へトルクを掛けている起動秤値が小さい。

→The starting weighing value applying torque in the DN direction is too small.

(3)E系エレベータで起動ショックが発生することは少ないため基本調整しない。

Starting shock rarely occurs in E-series elevators, so this is generally not adjusted.\n
