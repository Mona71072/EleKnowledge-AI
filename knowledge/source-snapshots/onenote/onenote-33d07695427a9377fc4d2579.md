レゾルバ誤差学習

Resolver Error Learning

(1)作業内容

Work Procedure

①赤外線リモコンにてモードを設定し、手動または高速で運転を行い、誤差学習を実施させる。

Set the mode using the infrared remote control, then operate the car manually or at high speed to perform error learning.

(2)目的

Purpose

①学習運転時に学習用誤差を与えながら運転し制御精度を上げ、振動・騒音といった運転時に起きる負の要素を補正することによって除去し、より良い乗り心地で運転を行えるようにしている。手動または高速での運転に精度の差はない。

During learning operation, the car is operated while applying learning errors to improve control accuracy, eliminate negative elements such as vibration and noise by compensation, and enable operation with better ride comfort. There is no difference in accuracy between manual and high-speed operation.

②誤差学習中は、学習用誤差を与えているため、振動及び騒音が発生するが問題ない。

During error learning, vibration and noise may occur due to the applied learning error, but this is normal.

③高速運転調整後に振動及び騒音が気になる場合、誤差学習を実施することで改善することがあるため、再度実施する。

If vibration and noise are noticeable after high-speed adjustment, performing error learning again may improve it, so repeat the procedure.

④電源投入直後も位相再推定のため、振動・騒音が発生することがあるが一定距離走行することで解消するので不具合と間違えないように注意すること。

Immediately after power-on, vibration and noise may occur due to phase re-estimation, but this will resolve after traveling a certain distance, so do not mistake it for a malfunction.

⑤レゾルバ誤差学習が完了していない場合、エラーコード「95D」が表示される。

If resolver error learning is not complete, error code "95D" will be displayed.\n
