**Precautions Rewriting Memory Compare Date**

When rewriting Memory Compare date, temporarily backed-up adjustment date is written to the RAM area.

When the P1 board is on the MNT side, performing a CPU reset transfers the date from RAM to flash ROM.

If the P1 board is on the MNT side and the CPU reset operation is forgotten, the field adjustment date cannot be written back to flash ROM.

As a result, the field adjustment date may not be reflected when checking Memory compare, or the date may be lost when the power is turned off.

Be sure to perform the CPU reset operation.\n
