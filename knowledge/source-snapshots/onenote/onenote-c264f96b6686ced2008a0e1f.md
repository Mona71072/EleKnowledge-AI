秤装置の設定（NL＋カゴ上作業者一人）

Weighing Device Setting (NL + One Worker on Car Top)

(1)作業内容

Work Procedure

①秤装置の傾斜センサーをロープ及びカゴ積載により決められた角度へ設定する。

Set the tilt sensor of the weighing device to the specified angle using the ropes and car load.

(2)目的

Purpose

①極端に傾斜センサーの角度がおかしいと、秤値異常を検出し高速運転が行えないため秤値を書込むまでの仮設定を行い運転を可能とする作業。

If the tilt sensor angle is extremely incorrect, it will detect a weighing value abnormality and prevent high-speed operation. This procedure performs a temporary setting to enable operation until the weighing value is written.

②傾斜センサーはカゴ内負荷BL（50％）で垂直（目盛の０）になるよう設計されているため、それを見込んだ設定をしている。

The tilt sensor is designed to be vertical (scale reading 0) at 50% car load (BL), so the setting is made with this in mind.

③本作業は、簡易的な設定のため精度は低い。後の作業で実際にオモリを使用して再度傾斜センサーの本設定を行う。

This procedure is a temporary setting and has low accuracy. The final setting of the tilt sensor will be performed later using actual weights.

20.秤装置とは・・・カゴ側シャックルバネの撓み量を傾斜センサの傾きに変換し、傾斜センサの傾き角度を演算処理することで、カゴ内負荷質量を求めている。

What is a Weighing Device...? It converts the deflection of the car-side shackle springs into a tilt sensor's inclination, and by processing the tilt sensor's angle, it determines the car's internal load mass.

21.全シャックルバネの撓み量を加算し傾斜センサの傾き角度に変換するため、ロープ張力のアンバランスやシャックルバネのバネ定数誤差の影響が少ない秤装置である。

Since it sums the deflection of all shackle springs and converts it into the tilt sensor's inclination angle, this weighing device is less affected by rope tension imbalance or shackle spring constant errors.
