# 最上階ホールランタン — 上/下用取違え

## 使う場面・対象条件

**最上階ホールランタン不点灯** — **NSA まで電圧あり**（Lists 267）。

## 症状・現象

- ST **ロータリー OK**（Lists）。

## ソース要約

### Lists（267）

- **最上階用** と **最下階用** が **テレコに誤結** — **リード線（ハーネス）群番が異なる**（Lists）。
- 適正器具へ取替で復旧（Lists）。
- **DC 電源保護** で一時不点灯の例は [249](../practice-guides/KH-ALL-DC-SUPPLY-PROTECT-RESET-249.md)（Lists 別件）。

## 統合した回答・ノウハウ

[289 FL1/HOS](./KH-ALL-HOS-FL1-HALL-LANTERN-289.md)・[15 ホール釦](./KH-VFGH-HALL-BUTTON-ZONE-15.md) と **乗場表示系** — 本件は **ランタン品種**。

## 調査・確認手順

1. **最上/中間/最下** 用 **3 群番** 確認。
2. テレコ **上/下用** 誤結有無。
3. NSA 電圧 vs 器具側配線。
