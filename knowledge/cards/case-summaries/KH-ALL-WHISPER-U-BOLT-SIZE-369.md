# ウィスパーフレックス混吊 — Uボルト径間違い破断

## 使う場面・対象条件

**QL-100 / QL-150 混吊** で **Uボルト破断**（Lists 369）。

## 症状・現象

- **QL-150 側に M8**（正規 **M10**）使用（Lists）。

## ソース要約

### Lists（369）

- **メカニズム**: ゴム座劣化 → **曲げ疲労** → ピット干渉 → **カウンター側破断**（Lists Notes）。
- **製品品質**: Q-3786（2023/7）。

### OneNote

- タイトル一致索引なし。

## 統合した回答・ノウハウ

**重量違い 2 本吊り** は **Uボルトサイズ** を型番ごとに確認。

## 調査・確認手順

1. 各本 **QL 型式** と **Uボルト径**。
2. かご下 **ゴム座** 状態。
3. 破断履歴 **Q-3786** 参照。
