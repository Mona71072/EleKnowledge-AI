# デジタルサイネージ — ツイストペア映像ノイズと部品配置

## 使う場面・対象条件

**デジタルサイネージ**（副操作盤映像）を **ツイストペア→同軸変換** で出す現場。光ケーブル比 **ノイズ乗りやすい**（Lists 178）。

## 症状・現象

- 改造後 **映像乱れ・時々出力停止**（YP752B067/068 系、Lists）

## ソース要約

### Lists（178）

- **原因（報告）**: **ビデオトランス＋ケーブル補償器** が重畳ノイズを **増幅**。
- **切り分け（progress 要約）**: DVD ポータブルで **かご下/上/内** 出力比較、トランス・補償器 **前後** で差。トランス/補償器を **同軸延長端子化** で低減、最終 **入力端子直前ノイズ対策** で許容画質。
- **背景**: 稲電仕様外 → 工期で **余りツイストペア変換** に変更（Notes）。

### OneNote

- タイトル一致索引なし。

## 統合した回答・ノウハウ

ノイズ時は **結線分離・テープ** だけで足りない例あり。**178 progress** の **部品前後比較** が Lists 上の診断骨格。正式改造は **営設・稲電確認** 前提。

## 調査・確認手順

1. 制御盤 **外部映像入力 + ポータブル DVD**（Lists 確認方法）。
2. 出力位置（かご下 JB / 上 / 内）の画質差。
3. **ビデオトランス・補償器** 前後。
4. 強電との分離・ワンタッチ化等（Lists ②③ — 効果なし例も記載）。
