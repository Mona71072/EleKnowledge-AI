# 負荷試験 110% で E-stop — トランス容量・SW_ACFST

## 使う場面・対象条件

**MRL 機種** で **負荷試験 110%** 中 **E-stop** するが **E-stop 後エラー表示なし** のパターン（Lists 437）。**109**（TR 端子脱落）とは無関係。

## 症状・現象

- 負荷試験 **110%** で **E-stop**（Lists タイトル）
- E-stop 後 **エラー表示なし**（Lists）
- 詳細症状: **情報管理確認まで保留**（スナップショット）

## ソース要約

### Lists（437）

- **調査（要約）**: 客先電源仕様は系統図どおり（例: 16.5kVA、ケーブル約 90m、60sq）。100% で約 60A、110% E-stop 時 **約 15A** — 電圧降下より **EV 側制御 E-stop** 疑い。
- **TR/リアクトル短絡試験**: 110% で **E-stop せず**（開発見解: 負荷軽減で異常検出しなくなっただけ、との記載）。
- **パラメータ KC_DAJ903**: 02/03 変更も **改善せず**。
- **原因（報告）**: **トランス容量不足による電圧降下** → 制御盤入力低下 **SW_ACFST** → E-stop。
- **対応**: **トランス増設**、110% **5 回 E-stop なし** 確認。

### OneNote

- タイトル一致索引なし。

## 統合した回答・ノウハウ

110% E-stop でエラーが出ないときは **AC 電源低下検出** と **客先 TR 容量** を Lists 437 の切り分け（短絡試験・電流プロファイル）で疑う。パラメータだけでは足りなかった例。

## 調査・確認手順

1. 仮設/本設差、客先 **容量・ケーブル径・長さ**（系統図照合）。
2. 100% / 110% **電流**（Lists 値の再現測定は現場判断）。
3. TR/リアクトル **短絡試験** の解釈（開発コメント参照）。
4. **SW_ACFST** / 入力電圧波形（正式手順は KB 未レビュー）。
5. **トランス増設** 等の設計対応。
