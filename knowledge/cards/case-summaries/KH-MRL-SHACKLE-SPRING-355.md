# MRL — シャックルばね取付間違いで秤ワイヤー余り

## 使う場面・対象条件

**秤装置ワイヤー** が **長く正規取付不可** — **L 番違い** を疑う前に **ばね**（Lists 355）。

## 症状・現象

- **据付工程**（Lists）。

## ソース要約

### Lists（355）

- **原因**: **かご側 74 mm** と **おもり側 107 mm** **特性違い** の **シャックルばね** を **逆取付** → 滑車位置ずれ・ロープ余り。
- **Notes**: 容量拡張 MRL / LINKs / 新 AXIEZ ごとの **自由長さ表**、CAP・ロープ径の理由（Lists 長文）。
- **Referenced**: IN-EL-08-093-01、C-19-S1.1。

### OneNote

- スナップショット照合: Lists §355 の **タイトル一致・ID 索引未検出**（Lists のみ。OneNote 追探索は別途）。


## 統合した回答・ノウハウ

[340](../practice-guides/KH-MEBL-SCALE-LOCK-PIN-340.md)（ME-BL **出荷固定金**）— **355** は **端末ばね**。

## 調査・確認手順

1. かご/CWT **端末ばね** 自由長さ（Lists Notes 表）。
2. 滑車 **正規位置** vs 実位置。
3. L 番違い **前** にばね型番。
