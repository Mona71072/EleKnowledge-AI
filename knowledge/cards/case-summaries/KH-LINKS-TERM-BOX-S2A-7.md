# LINKs — 終点 S2A/S1A 嵌合で本スロー不出

## 使う場面・対象条件

**AXIEZ-LINKS** **WOS 後** **本スローでカゴ不動**（Lists 7）。

## 症状・現象

- WOS は可、**本スロー不可**（Lists）。

## ソース要約

### Lists（7）

- **原因**: **上部 S2A / 下部 S1A** コネクタ **嵌合外れ** 疑い — 確認後本スロー復帰（Lists）。
- **progress**: **29 切** → R1 **SC2-SCH 短絡** でかご上可；**RDF/RDT** UOT/DOT 導通確認（Lists）。
- C-7-C3900 P37（Lists — pending）。

## 統合した回答・ノウハウ

[27 G6](./KH-LINKS-BLOCKING-DEVICE-G6-27.md)・[392 BK](./KH-VFGLF-BRAKE-SW-392.md) と **本スロー不出** を分岐 — **終点箱嵌合** は Lists 7。[12 DL](../practice-guides/KH-LINKS-DL-SHORT-12.md) も **S2A** 共有語彙。[229 下部 BOX 腕](../practice-guides/KH-LINKS-LOWER-TERM-BOX-MOUNT-229.md) は **取付位置**。

## 調査・確認手順

1. WOS vs **本スロー** のみか。
2. 上 **S2A**・下 **S1A** 嵌合。
3. 29 / SC2-SCH 短絡試験（Lists progress）。
4. RDF/RDT **UOT/DOT** 導通。
