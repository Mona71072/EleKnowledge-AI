# SD-T21（#5/M5/LBA）コンタクタ不吸引

## 使う場面・対象条件

**VFGLF** の **SD-T21（#5, M5, LBA）** で、**A1-A2 間に 48V あるのにコンタクタがピックアップしない**（しようとして完遂しない）とき。Lists ↑高。

## 症状・現象

- A1-A2 48V 電位差でも不吸引 / 不完全吸引
- 報告エラー: 432, 452

## ソース要約

### Lists（list_item_id 96）

- **原因**: 不明。
- **暫定対応**: **#5 と M5 コンタクタ入替** 可能。**交換前に #5 の電圧確認** し他原因排除。
- **制約**: **M5 を #5 と入替えると MELD 運転が使用不可**（Lists 注意）。
- **電圧条件の切り分け（Notes）**: A1 に 48V 無し、A2 に 48V 有り等は **別原因**。
- **progress**: 不発返却品で再現性あり、調査中。

### OneNote

- list タイトル **一致页なし**。

## 統合した回答・ノウハウ

#5 不吸引はいきなり入替せず、Lists が示す **A1/A2 の 48V パターン** で制御回路側を除外してから **#5↔M5 暫定** を検討。**MELD 不可** の副作用を必ず共有。根本原因は Lists 上未確定（返却品調査中）。

## 調査・確認手順

1. 432/452 表示を記録。
2. #5 の **A1・A2 対地電圧** を Lists Notes どおり解釈（48V パターン異常 → 別経路）。
3. A1-A2 48V 正常域で不吸引 → 不発品再現性を踏まえ **#5 本体** を疑う。
4. 暫定: #5↔M5 入替前に電圧再確認（Lists 必須）。
5. 入替後 **MELD 運転不可** を試験計画に反映。
