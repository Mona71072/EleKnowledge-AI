# 型板設定 — ピアノ線間寸法（IN-EL-08-111 / Excel）

## 使う場面・対象条件

**MR 機種** の **型板設定** で **ピアノ線間寸法** を求められるとき（Lists 396 — 問い合わせ稀）。

## 症状・現象

- 手計算に **時間がかかる**（Lists）

## ソース要約

### Lists（396）

- **対応**: **IN-EL-08-111 P3-18** 計算式を **Excel** 化 — 各寸法入力で線間寸法を出力。
- **Notes**: **CJ / CA 寸法の ±** に注意。Excel も Lists 添付参照。

### OneNote

- タイトル一致索引なし。

## 統合した回答・ノウハウ

手計算より **IN-EL-08-111 式＋Lists 配布 Excel** を正とする。符号ミス（CJ/CA）が Lists で明示されている注意点。

## 調査・確認手順

1. 型板関連寸法を現場計測。
2. IN-EL-08-111 **P3-18** 式または Lists Excel に入力。
3. CJ/CA の **±** 確認（Notes）。
4. 結果を型板設定記録へ（手順詳細は KB 未レビュー）。
