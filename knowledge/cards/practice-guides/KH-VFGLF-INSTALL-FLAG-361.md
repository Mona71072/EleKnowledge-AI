# 据付け中認識フラグ — 引渡し完了で OH 制限（1009 30CF）

## 使う場面・対象条件

**VFGLF** で **据付け中認識** が **引渡し完了** になり、**かご上/ピット運転制限** で OH・調整が止まるとき。

## 症状・現象

- フラグ **引渡し完了** → **かご上/ピット運転制限** 有効（Lists）
- P1 **R/M 放置** で引渡し完了に進んだ **推測**（Lists 原因）

## ソース要約

### Lists（361）

- **段階**: 据付中 → 据付完了 → **引渡し完了**。**P1 RSW だけでは前段階に戻せない**（例: 引渡し完了→据付中不可）。
- **戻し**: メンテコン — アドレス **1009 30CF** — **FF** 据付中 / **01** 据付完了 / **00** 引渡し完了。設定後 P1 で **MON1/0=8/F** 反映確認。
- **参照**: C-7-C3900 P.107, 130。
- **Notes**: 稲電 **非推奨**、協力会社非開示、変更前稲電確認。

### OneNote

- タイトル一致索引なし。

## 統合した回答・ノウハウ

保守対応後に **P1 R/M のまま離脱** すると引渡し完了に進み得る（Lists）。復帰は **85（AXIEZ）と別アドレス** — 機種を見てカードを選ぶ。

## 調査・確認手順

1. 運転制限症状が **据付フラグ** 由来か（Lists 361 症状）。
2. 現フラグ段階（MON/メンテコン）。
3. 稲電確認後 **1009 30CF** 書換。
4. **MON1/0=8/F** で反映確認。
5. 引渡し前に **意図した完了状態** を再確認（Notes）。
