# 稲電部品手配 — MiLai 物流と図面番号要求

## 使う場面・対象条件

**稲電部品** を現場手配するときの **入口手順**（Lists 311）。

## 症状・現象

- 事務・手配 **周知**（Lists observed: 事務関係）。

## ソース要約

### Lists（311）

- **流れ**: MiLai **「一般部品・オイルロープ要求」** → オーダー入力 → **図面番号選択** → 図番・部品名・数量・寸法等。
- **注意1**: **図面番号手配**（部品番号なし）時は **MTB 資材** と納期・数量相談（資材が稲電へ掛合）。
- **注意2**: **赤外線リモコン（特注）** は **OAP** 連絡。
- 電話番号は Lists にあるが **スナップショット省略**。

### OneNote

- タイトル一致索引なし。

## 統合した回答・ノウハウ

[247 カシメ付きリード](./KH-ALL-CRIMP-LEAD-HARNESS-ORDER-247.md)・[236](./KH-ALL-CONNECTOR-ORDER-236.md)（コネクタ手配索引）と **手配経路** が異なる場合あり — **311** は **MiLai 一般部品** 入口。

## 調査・確認手順

1. 図面番号／部品番号の有無。
2. MiLai 物流 **一般部品要求**。
3. 図番のみなら **MTB 資材** 相談。
4. 特注（赤外線等）→ **OAP**。
