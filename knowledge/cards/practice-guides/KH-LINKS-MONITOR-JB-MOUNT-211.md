# 監視盤 JB — 設置階と取付高さ

## 使う場面・対象条件

**監視盤 JB（ツナギ箱）** の **設置階・高さ** 不明（Lists 211）。

## 症状・現象

- 取付位置問合せ（Lists）。

## ソース要約

### Lists（211）

- **位置**: **C-41**「監視盤ツナギ箱設置（YE402B112）」— **エレコード・かごレール** で分岐（Lists）。
- **高さ**: **入線口・ケーブル長** から **最下/中間/最上** — 基準 **YE402B112**、**IN-EL-12-107-10**（Lists — pending）。
- 例: **入線口が昇降路頂部** → **最上階付近**（Lists）。
- **KM-LD / KE-*F** も C-41 図・据付ノート（Lists Notes）。
- LINKs は品目 **「ツナギバコカイ FL=」** なし — **加工長直接記載**（Lists Notes）。
