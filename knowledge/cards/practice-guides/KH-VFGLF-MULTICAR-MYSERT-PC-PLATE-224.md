# 異制御マルチカー — マイサート盤 PC 取付板形状

## 使う場面・対象条件

**LINKs + KM-LD 等 異制御マルチカー** で **増設盤の PC 取付板** 取付不明（Lists 224）。

## 症状・現象

- 「**よくわからない部品**」問合せ（Lists）。

## ソース要約

### Lists（224）

- **ルール**: 異制御 MC は **最新制御が優先** → **LINKs マイサート盤がキーカー側**（Lists）。
- 本現場は **KM-LD がキーカー** 想定で **マイサートが KM-LD 側** — **板形状が従来と異なり混乱**（Lists）。
- **取付資料添付**（Lists Notes）。

### OneNote

- タイトル一致索引なし。

## 統合した回答・ノウハウ

[259 KM-LD PC 板干渉](../case-summaries/KH-KM-LD-PC-MOUNT-PLATE-259.md) は **KE-LG 流用・カバー干渉** — **224** は **異制御 MC の盤付けルール** と **板形状変更**。[264 扉金具](./KH-KM-LD-DOOR-TRANSPORT-BRACKET-264.md) と **KM-LD 現場部品** 同桶。

## 調査・確認手順

1. **キーカー号** と **制御形式**（LINKs / KM-LD）。
2. **マイサート盤** が **最新制御側** か。
3. Lists 添付 **取付図**（本文未転載）。
4. 干渉疑い → **259** 参照。
