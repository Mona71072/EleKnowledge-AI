# VFGH — ピット点検口と GOV 張車（出入り不可）

## 使う場面・対象条件

**ピット点検口** 前 **GOV 張車** で **出入り不可**（Lists 413）。

## 症状・現象

- **Reported symptoms**: ピット点検口の前に GOV 張車（Lists）。
- **Reported cause**: 情報管理保留 — 再掲しない。

## ソース要約

### Lists（413）

- **Notes**: **2 台同時停止** 了承が **管理会社で困難** な場合あり。**点検口位置変更** で **制御ケーブル金網と干渉** 類似あり。
- **progress**: **保守了承済・対策不要**（Lists）。

### OneNote

- タイトル一致索引なし。

## 統合した回答・ノウハウ

[270 施錠方式](./KH-ALL-INSPECTION-LOCK-TYPES-270.md)・[420 ケーブル吊り](./KH-MR-CONTROL-CABLE-HANG-420.md) と **ピット作業** 索引 — **413** は **GOV 物理配置**。

## 調査・確認手順

1. 点検口 **クリアランス**（GOV/CWT）。
2. **停止台数** と **管理会社** 合意（Lists Notes）。
3. 類似 **金網干渉** 有無。
4. 保守 **了承** 記録。
