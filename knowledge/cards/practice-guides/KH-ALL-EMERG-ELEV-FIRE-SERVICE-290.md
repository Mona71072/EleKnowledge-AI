# 非常用エレ — リア遮煙で火災管制必須

## 使う場面・対象条件

**非常用エレ** で **火災管制運転** の要否説明 — 監視盤・建築側問合せ（Lists 290）。

## 症状・現象

- 原則ロビー **耐火構造** で遮煙不要も、**リア広場** 等で **遮煙必須→火災管制必須**（Lists）。

## ソース要約

### Lists（290）

- 例 **CM-LB 2D2G**: フロント **遮煙なし**、リア **広場→遮煙ドア必須→火災管制**（Lists）。
- **全自運転** 時リア扉開放 → 防火区画失うリスク（Lists）。
- 監視盤 **火災管制キー SW** — 「間違いでは？」問合せ想定 → **営業設計に背景確認**（Lists Notes）。

## 統合した回答・ノウハウ

[227 遮煙+MELD](./KH-ALL-SMOKE-FIRE-SERVICE-MELD-227.md) が **大臣認定・MELD** 正本 — 本件は **非常用＋リア遮煙** の **適用説明**。[154 シャフト煙感知](../practice-guides/KH-MRL-SMOKE-SHAFT-DETECTOR-154.md) は別論点。

## 調査・確認手順

1. **フロント/リア** 防火・遮煙構成。
2. 品目 **火災管制** 有無。
3. 監視盤 SW 仕様。
4. 営業設計 **適用背景**（Lists Notes）。
