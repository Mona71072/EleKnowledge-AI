# SfleX-rope と非対称ソケット — 労基・構造規格

## 使う場面・対象条件

**MR** **SfleX-rope + 非対称ソケット** が **労働安全衛生法（エレベーター構造規格）** に適合するか — **建築基準法 OK でも労基目線で指摘**（Lists 278）。

## 症状・現象

- 労基から **端末緊結**・**SfleX 性能** 疑義（Lists）。

## ソース要約

### Lists（278）要点

- **構造規格 29 条**: バビット式 + **コッタ止め** — 図は **左右対称ソケット**（LINKs 型）。**非対称型** は明示確認漏れ → **愛知労基** に両型可の解釈照会 → **問題なし**。
- **SfleX**: 三菱承認の **非対称くさび式** に SfleX 言及なし → **JIS3525 以上性能を SfleX に認めよ** 照会 → **問題なし**。
- **運用**: SfleX は **添付必須**、普通ロープも労基要求時は **回答資料添付**（Lists）。
