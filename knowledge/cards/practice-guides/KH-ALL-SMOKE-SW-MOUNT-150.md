# 煙感知点検 SW — マイクロ vs リミット・取付金

## 使う場面・対象条件

**煙感知器点検 SW** の **マイクロ/リミット** と **新取付板/ブラケット** 選定（Lists 150）。

## 症状・現象

- 22 年度時点 **4 組合せ** の適用条件不明（Lists）。

## ソース要約

### Lists（150）

- **2012～**: BOX 改良型に合わせ **マイクロ SW + 新取付板** 標準。
- **旧 BOX**: 新取付板不可 → **リミット + ブラケット**（壁固定）。**YE400C054G12**（国営手配、2〜3 週）。
- **温泉等**: マイクロ不可 → **リミット + ブラケット**（稲電出荷）（Lists Notes）。

### OneNote

- なし。

## 統合した回答・ノウハウ

**90/87**（WOS/RHQ 短絡）と別 — **150** は **点検 SW 物理**。IN-EL-02-53.1 正本待ち。

## 調査・確認手順

1. BOX 改良型か。
2. 特殊環境（温泉）か。
3. 金具 **新板 vs ブラケット**。
4. 前広・手配リードタイム（Lists）。
