# 試験・検査 — 記録者・検認者と実施順

## 使う場面・対象条件

**試験・検査報告書** の **役割・日付順** が不明（Lists 251・↑高）。

## 症状・現象

- （運用豆知識）

## ソース要約

### Lists（251）

- **役割**: 受入検査者 / 工事完了試験者 / 工事完了検査者 / **最終検査者** / 工事品質責任者（Lists）。
- **順序**: 完了試験・完了検査 → **最終検査** → 品質責任者（試験と検査は入替可）（Lists）。
- **最終検査**: 官庁検査後〜契約納期で **早め**（Lists）。
- **同一者禁止**: 試験者・検査者・最終の **3 者同一 NG** 等（Lists）。
- 正本 **IN-EL-01-94**（Lists Notes — pending）。
