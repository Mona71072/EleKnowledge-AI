# 昇降路内 — 突起物・配管・防火扉配線

## 使う場面・対象条件

**昇降路内** の **出っ張り・無関係配管・防火扉配線の通し方** を建築・検査目線で整理するとき。正本整理は OneNote **:41 / :42**（Lists 単独豆知識 ID なし）。

## 症状・現象

- 昇降路に **他工种配線** や **不要な突起** がある。
- 「防火扉だから昇降路配線 OK」とされている。

## ソース要約

### OneNote（401f288f…:41 / :42）

- **令129条の7** — 原則 **突出物禁止**（例外のみ）。**1495号** — 許容ブラケット等への **地震時索引防止**（任意突起の全面許可ではない）。
- **令129条の2の5** + **告示570号** — 昇降路配管は **エレ必要配管 / 導体なし光ファイバ / その配管** に限定。
- **非常用エレ** も同原則。
- **防火扉配線** — 扉として必要でも **昇降路幹線ルートとして当然可ではない**。最小接続・別経路を検討。

## 調査・確認手順

1. 昇降路内設備の **用途**（エレ専用か）。
2. ブラケット等が **1495号** 適合か。
3. 配管が **570号** 3 区分か。
4. 防火扉線の **経路図**（昇降路縦通しの有無）。
