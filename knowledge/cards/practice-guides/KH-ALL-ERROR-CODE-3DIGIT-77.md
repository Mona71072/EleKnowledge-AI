# 3桁エラー — 桁の見方（豆知識）

## 使う場面・対象条件

**3桁エラー** が複数出て **どれを先に潰すか** 整理するとき（Lists 77）。

## 症状・現象

- 自動で **かごが動かない**（Lists）。

## ソース要約

### Lists（77）

- **100の位**: 大分類（種別）。
- **10の位**: **重篤度** — **小さいほど重症**。**10の位 ≤3** → **自動では動かない** と認識（Lists）。
- **1の位**: 小分類（部位等）。
- **対応のコツ**: *4*/*5* が多くても **\*3\***/*1* 等 **より重篤** を先に（Lists）。

## 統合した回答・ノウハウ

Lists 上の **優先度ヒューリスティック** — 機種別正本は各 C／トラブルシュート（未突合）。

## 調査・確認手順

1. 表示中 **3桁コード** を列挙。
2. **10の位** で並べ替え（小さい＝先）。
3. 10の位 ≤3 なら **自動不可** 前提で原因追及。
4. 機種別 **小分類表** で 1の位を解釈（KB 待ち）。
