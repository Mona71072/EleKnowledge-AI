# エレベーター荷扱い基準（一度の積載量）

## 使う場面・対象条件

**工事使用** で **重量物一括積載** → **秤 VB 狂い** 等（Lists 367）。

## 症状・現象

- 高所作業車・**1.2 t ドラム** 等で **秤管理外**（Lists MR 例）。

## ソース要約

### Lists（367）

- **定格積載 ≠ 一度の積載可** — 手荷物・手押し台車想定。
- **規格 CAP1000 未満**: 常用/寝台/人貨 **250 kg**（車輪 **62.5 kg/輪** 目安）。
- **CAP1000 以上**: 常用 250 kg、寝台/人貨 **500 kg**。
- **Notes**: ASME A class loading **25%** 由来 — CAP から導出した **容量上限ではない**。

### OneNote

- タイトル一致索引なし。

## 統合した回答・ノウハウ

現場 **分割搬入**・台車分散 — [347 ランバイ](../practice-guides/KH-MRL-RUNBY-SPACER-347.md) 等 **機械** とは別軸。

## 調査・確認手順

1. S-14-120.1-J 確認。
2. 積載 **250/500 kg** 上限と **車輪荷重**。
3. 秤 **VB** 異常時は **過荷重** 疑い。
