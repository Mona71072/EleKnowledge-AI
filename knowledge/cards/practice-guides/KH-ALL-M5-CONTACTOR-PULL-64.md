# #5 コンタクタ — 安全回路 OK でも不吸引

## 使う場面・対象条件

**#5（M5）が引かない** が **#29 安全回路は正常** と見えるとき（Lists 64・豆知識）。

## 症状・現象

- #5 不吸引、走行不可（Lists）。

## ソース要約

### Lists（64）

- **#5**: A1–A2 **電圧差** で吸引。#29 正常なら A1 に 48V も **引く指令なし** なら A2 は 0V 接続されず **不吸引**（Lists）。
- **確認**: バック接点で ON/OFF。**不吸引時 R1 上 R5 に電圧**（機種差あり）。**R5 無電圧＝引く指令なし**（Lists）。
- **4\*\*** エラーは **先に対応**（Lists エラー表示欄）。

## 統合した回答・ノウハウ

安全回路 OK だけでは不十分 — **コンタクトカウント表** で #5 バックと **R5**（Lists）。

## 調査・確認手順

1. **4\*\*** 系を優先処理。
2. #5 A1/A2、#29 状態。
3. ストレート **#5 バック接点**。
4. **R5 電圧**（Lists）。
